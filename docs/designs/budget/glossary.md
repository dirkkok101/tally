# Budget Planning — Glossary

> Generated from the lex graph. Do not edit this file as source of truth; update graph entities and re-export.

| Term | Definition | Source |
|---|---|---|
| Active Budget Plan Revision | The single explicitly activated Budget Plan Revision whose planned amounts govern the current Budget Position for its Budget Period. |  |
| Budget Actual | The exact transfer-, refund-, correction-, allocation-, void-, and supersession-aware aggregate returned by LEDGER for the requested snapshot and period. BUDGET does not reinterpret it as gross debits or total outflow. |  |
| Budget Period | One explicit monthly date interval for which the owner records spending intent; its boundaries and identity are stable and never inferred from invocation time. |  |
| Budget Plan | The stable owner planning identity for one Budget Period, containing a history of draft, active, and superseded Budget Plan Revisions. |  |
| Budget Plan Revision | An immutable version of a Budget Plan containing exact Category Budget Entries plus owner, reason, lifecycle, and creation provenance. |  |
| Budget Position | A deterministic snapshot-bound comparison of one explicit Budget Plan Revision with public LEDGER actuals. Without a revision selector it uses the single Active revision; an explicit Draft, Active, or Superseded revision may be evaluated without changing lifecycle state. The result returns exact planned, actual, remaining or over, Unbudgeted Spend, and Uncategorized Spend values plus revision status and provenance. | prd |
| Category Budget Entry | An exact ZAR planned-spend amount for one stable LEDGER Spend Category identifier within one Budget Plan Revision. It governs that exact Spend Category and every descendant Spend Category whose own frozen ancestry carries no nearer entry, per DD-BUDGET-CATEGORY-ENVELOPE-RESOLUTION. Parent and descendant entries may coexist in one revision. Avoid: budget line, budget item, allocation. |  |
| Closed Budget Period | A completed calendar-month Budget Period that accepts no new Draft or activation in v1 while its existing plan revision history remains readable. Do not call it editable history. | prd |
| Draft Budget Plan Revision | An immutable proposed Budget Plan Revision that has not been activated. Saving it does not change the Budget Position. Do not call it a working active budget. |  |
| Planned Spend | The exact ZAR amount in a selected Budget Plan Revision for a Category Budget Entry or the revision total. Its lifecycle status shows whether it is proposed Draft intent, owner-approved Active intent, or retained Superseded intent; it is never an actual or forecast. | prd |
| Public Budget Operation | One versioned channel-neutral BUDGET capability using the canonical Create Draft, Get Plan Revision, List Plan Revisions, Activate Plan Revision, Get Budget Position, or Discover Contract vocabulary. It is not an HTTP endpoint or UI action. | prd |
| Superseded Budget Plan Revision | A formerly active Budget Plan Revision replaced by an explicit activation and retained in history. Do not call it a deleted old budget. |  |
| Unbudgeted Spend | Actual spend assigned to a valid Spend Category for which no element of that Budget Actual's frozen Spend Category ancestry carries a Category Budget Entry in the selected Budget Plan Revision. Spend on an unplanned Spend Category whose ancestry does carry a nearer entry is not Unbudgeted Spend; DD-BUDGET-CATEGORY-ENVELOPE-RESOLUTION assigns it to that nearest entry. Avoid: unplanned spend, uncategorized spend. | prd |
| Uncategorized Spend | Actual spend that LEDGER reports without a current Spend Category assignment; BUDGET exposes it separately and never treats it as zero or invents a plan category. |  |
| Zero Budget | An explicit Category Budget Entry of exactly ZAR 0.00, expressing that no spend is planned for the Spend Category; it is not the same as omission. Because it is an explicit entry, it terminates ancestry resolution and blocks fallback to a funded ancestor, so spend at or below it is reported against the Zero Budget Position rather than the ancestor. Avoid: no budget, unbudgeted. |  |
