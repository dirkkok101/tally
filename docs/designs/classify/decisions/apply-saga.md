## Description

Close every cross-store crash window while keeping all-item preflight and explicit owner mutation authority.

## Decision

Persist an expiry-bound preview over one current Evaluation Fingerprint and an exact selection after purpose=apply_preflight returns every selected identity, Ledger-owned mutation state, current allocation identity, and lifecycle revisions. Apply acquires a per-run owner lock, repeats that all-item preflight, and rejects the whole run before mutation on any drift. For each item in deterministic transaction order, durably freeze the exact public Ledger operation, target, expected allocation and revisions, correction reason, request fingerprint, and derived per-item idempotency key; invoke Ledger outside the CLASSIFY transaction; and durably record the terminal result before advancing. Resume replays only planned or unresolved items with the exact frozen request and key.

## Rationale

A distributed transaction across separate stores does not exist. Holding a CLASSIFY SQLite transaction across Ledger calls creates locks without atomicity. A requires-independent-decision query cannot inspect explicit corrections, and preflight without Ledger-enforced allocation and revision conditions leaves a race before each write. Calling Ledger before durable intent loses the recovery frontier. Storing only an aggregate receipt cannot reconcile individual commits. The purpose-scoped preflight, frozen preconditions, and Ledger idempotency close drift, commit-before-result, and result-before-CLASSIFY-durability windows while preserving a precise test surface.

## Alternatives

Rejected a cross-store transaction or holding a CLASSIFY SQLite transaction across LEDGER calls because neither makes the two stores atomic. Rejected invoking LEDGER before durable per-item intent because interruption loses the recovery frontier. Rejected aggregate-only apply receipts because they cannot reconcile individual commits. Rejected per-item-only preflight because later drift could permit partial mutation after the owner authorized a different complete selection.
