# Pure ordered evaluation with fingerprint-bound evidence

> Generated from the lex graph. Do not edit this file as source of truth; update graph entities and re-export.

**Status:** accepted
**Ref Code:** DD-CLASSIFY-DETERMINISTIC-EVALUATION

## Description

Produce one reproducible suggestion, no-suggestion, conflict, or stale outcome without hidden precedence or Ledger mutation.

## Decision

Acquire the full bounded Ledger projection before evaluation, process items by projection ordinal and rules by stable version ID, combine compatible same-category matches, and fail incompatible categories to conflict with no winner. Persist one atomic evaluation containing every outcome, aggregate counts, canonical fingerprint dimensions, and evidence limited to rule, condition, field, predicate, and normalized-value hash references. Outcome inspection never reconstructs missing evidence from current state.

## Rationale

Streaming partial durability could publish incomplete results. Priority-based winners hide ambiguity. Persisting full projection payload creates unnecessary financial retention, while storing no evidence makes historical explanation impossible. The bounded metadata evidence is sufficient for the PRD contract. A pure engine plus one atomic store commit keeps the interface equal to the verification surface.

## Alternatives

Rejected priority-based winning rules because they hide incompatible-category ambiguity. Rejected streaming partial outcome durability because it can publish incomplete evaluations. Rejected persisting full projection rows or raw matched values because it retains unnecessary financial payloads. Rejected retaining no evidence and reconstructing from current state because later explanations would not describe the original decision.
