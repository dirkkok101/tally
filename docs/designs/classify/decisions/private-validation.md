# Memory-only private corpus validation with aggregate durability

> Generated from the lex graph. Do not edit this file as source of truth; update graph entities and re-export.

**Status:** accepted
**Ref Code:** DD-CLASSIFY-PRIVATE-VALIDATION

## Description

Gate rule and normalization activation on representative owner evidence without retaining or disclosing raw financial rows.

## Decision

Read one bounded owner-only JSONL corpus path only from private structured input, open read-only without following the final symbolic link, fingerprint exact bytes, and stream rows through the production normalization and evaluation engine. Persist only candidate, corpus, expected-outcome, projection, category, and normalization fingerprints plus aggregate counts and canary outcomes. Require current evidence with zero incorrect-application canaries and zero unexplained incompatible conflicts before activation or broad authority.

## Rationale

Copying corpus data into the state store or graph increases disclosure and retention. An external validation service violates locality. A separate evaluator risks semantic drift. Aggregate-only durability satisfies activation proof while the production engine makes validation representative. If the corpus is unavailable, preserving the last active rule set but blocking new authority is the only fail-closed behavior consistent with the PRD.
