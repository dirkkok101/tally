#### Validate the owner-authored rulebook before authority

**Ref Code:** TC-CLASSIFY-OWNER-RULEBOOK-PRE-AUTHORITY-GATE
**Surface:** contract
**Automation:** automated
**Status:** planned
**Owner:** Personal Finance Owner
**Implementation Ref:** DD-CLASSIFY-OWNER-RULEBOOK-REPLACEMENT

##### Preconditions

The candidate rulebook and expected outcomes are owner-only runtime inputs outside tracked paths; the released classification_v1 Ledger contract, production normalizer, rule evaluator, draft save, and rule validation operations are available.

##### Steps

Run the aggregate-only gate twice over the same private candidate set; account for every row; compare deterministic fingerprints; exercise expected suggestions, explicit no-suggestions, expected conflicts, mixed-purpose rows, sign and account conditions, fee-versus-purchase separation, transfer and linked-refund exclusions from Ledger truth, drift canaries, and owner decision/time measurements; scan every durable and diagnostic output for forbidden payload classes.

##### Expected

##### Cleanup

Remove only recognized disposable gate artifacts; retain aggregate receipt and immutable validation fingerprints; leave owner-only source inputs unchanged.
