## BoundInsightEvidence

**Ref Code:** DM-INSIGHTS-COHERENT-EVIDENCE

INSIGHTS-owned validated projection of one BUDGET composite result across bound and absent plan states; it is ephemeral and never a second source of truth.

### Schema

BoundInsightEvidence {budgetPeriod, planState, planRevisionDetail?, budgetPosition?, datedActualMembers[], ledgerBudgetActualTotal, categoryLifecycleEvidence, budgetContractVersion, ledgerContractVersion, ledgerSnapshotId, ledgerGenerationFingerprint, calculationSchemaVersion?, evidenceBindingFingerprint}.
Plan states: BoundRevision | NoBudgetPlan | NoActiveBudgetPlanRevision.
DatedActualMember {ordinal, stableTransactionEvidenceId, effectiveDate, signedActualMinorUnits, stableCategoryId?, bucketKind}.
BoundRevision invariants: planRevisionDetail, budgetPosition, and calculationSchemaVersion are present; one complete ordered member set shares the position snapshot and generation; every member reconciles exactly once to Budgeted, ZeroBudget, Unbudgeted, or Uncategorized; checked member totals equal both ledgerBudgetActualTotal and BudgetPosition actual totals.
Plan-absence invariants: planRevisionDetail, budgetPosition, and calculationSchemaVersion are absent; no zero or empty plan is fabricated; the complete ordered members remain present; their checked exact sum equals ledgerBudgetActualTotal; calculator invocation is forbidden.
All states fail whole-report binding on unknown, duplicate, missing, stale, incompatible, over-limit, or mismatched evidence.
Ephemeral only: no member, cursor, plan, or position payload is stored by INSIGHTS.

## InsightsIdempotencyRecord

**Ref Code:** DM-INSIGHTS-IDEMPOTENCY

Module-wide replay identity and immutable outcome references for every retained-state or recovery mutation.

### Schema

InsightsIdempotencyRecord {operationId, contractVersion, keyDigest, requestFingerprint, state: Attempting|Succeeded, outcomeKind: Snapshot|NoChange|Deleted|Backup|Restore, outcomeRef, outcomeFingerprint, createdAt, completedAt?}.
Unique key: operationId plus contractVersion plus keyDigest.
Canonical request fingerprint includes all logical input, actor, reason, target or predecessor, selected policies, expected-current fingerprint, and safe normalized path identity where applicable.
Same key and fingerprint returns the prior logical outcome before producer reads or writes; changed fingerprint returns IdempotencyConflict.
Validation and transient failure do not consume a key. If a snapshot outcome was later deleted, replay resolves to metadata-only Deleted and never recreates content.

## InsightReport

**Ref Code:** DM-INSIGHTS-INSIGHT-REPORT

Complete bounded ephemeral analytical result and the canonical immutable payload retained by Report Snapshot.

### Schema

InsightReport {reportId, reportSchemaVersion, budgetPeriod, asOfInstant, analysisWindows[], planState, exactMetrics[], signalStates[], limitations[], sourceProvenance, policyVersions, orderingPolicyVersion, contentFingerprint}.
SourceProvenance {insightsContractVersion, budgetContractVersion, ledgerContractVersion, ledgerSnapshotId, ledgerGenerationFingerprint, budgetPlanId?, budgetPlanRevisionId?, categoryContractVersion, calculationSchemaVersion?, evidenceBindingFingerprint, analysisWindowPolicyVersion, formulaVersions[], sufficiencyVersions[], explanationVersion, orderingVersion}.
Canonical semantic payload contains every report field except derived reportId and contentFingerprint. contentFingerprint is SHA-256 over its source-generated canonical UTF-8 JSON; reportId is deterministically derived from that fingerprint and is inserted only after hashing.

## InsightPolicyCatalogue

**Ref Code:** DM-INSIGHTS-POLICY-CATALOGUE

Closed code-owned catalogue of active and deferred analytical policy versions and deterministic ordering.

### Schema

PolicyDescriptor {kind, version, status: Active|Deferred, schemaFingerprint, policyFingerprint, default, order, supportedWindows[], limitSetVersion}.
Active v1 policy kinds: AnalysisWindowPolicy, ExactMetricPolicy, LinearPacePolicy, EvidenceSufficiencyPolicy, ExplanationPolicy, OrderingPolicy.
Deferred v1 kinds: ForecastPolicy, TrendPolicy, AnomalyPolicy, AttentionPolicy; no executable formula, baseline, threshold, severity, or activation surface.

## PolicyValidationReceipt

**Ref Code:** DM-INSIGHTS-POLICY-VALIDATION-RECEIPT

Privacy-safe aggregate release and test evidence, stored outside the active INSIGHTS product store, that built-in analytical policies and the candidate report shape passed private gates.

### Schema

PolicyValidationReceipt {receiptId, policySetFingerprint, reportSchemaVersion, producerContractVersions, windowPolicyVersion, corpusFingerprint, expectedStateFingerprint, evaluationToolVersion, structuralCaseIds[], aggregateOutcomes, falseHighSeverityCount, disclosureCanaryStatus, ownerDecisionId, ownerAcceptedImprovement, createdAt}.
aggregateOutcomes counts Supported, Unavailable, InsufficientEvidence, CorrectSignal, IncorrectSignal, CorrectSeverity, FalseSeverity, and Canary outcomes.
Required shapes: sparse, zero, recurring, front-loaded, irregular, refund-heavy, plan-change, category-lifecycle, classification-gap, correction, and false-severity.
Forbidden fields: manifest filename or path, amount, merchant text, report payload, source row, expected row, or private case body.
Storage boundary: release or test evidence outside active insights.db; the released catalogue embeds only the passed policy and receipt fingerprints. A changed policy cannot enter the catalogue without a passing compatible receipt; unchanged released policies remain usable when the corpus is absent.

## ReportSnapshotRestatementAndDeletion

**Ref Code:** DM-INSIGHTS-RETAINED-REPORT-LIFECYCLE

Immutable retained report identity, explicit predecessor relationship, ordered difference evidence, and metadata-only deletion history.

### Schema

ReportSnapshot {snapshotId: ULID, reportId, canonicalReportPayload, payloadFingerprint, reportSchemaVersion, analysisRequestFingerprint, sourceFingerprint, policyFingerprint, createdAt, actor, reason}.
RestatementLink {childSnapshotId unique, predecessorSnapshotId, createdAt}; one predecessor per child; parent may have multiple surviving children.
RestatementDifference {sourceChanges[], policyChanges[], exactMetricChanges[], stateChanges[], explanationChanges[], attentionChanges[]}; stable section and item ordering; no unrelated source rows.
DeletionEvent {deletionEventId: ULID, deletedSnapshotId, predecessorSnapshotId?, deletedAt, actor, reason, dependencyResult, idempotencyOutcomeRef}; no amount, explanation, or report content.
Delete is RESTRICTed while any surviving child references the target. Leaf deletion removes payload and outgoing link atomically and retains the event. No automatic expiry.

## InsightsStateStore

**Ref Code:** DM-INSIGHTS-STATE-STORE

One logical owner-only raw-SQLite generation store for retained analytical evidence and module metadata.

### Schema

Root: one insights.db inside an owner-only generation directory selected by CURRENT.
Tables: store_metadata, report_snapshot, report_payload, restatement_link, deletion_event, insights_idempotency_record, recovery_receipt, restore_event.
Metadata: PRAGMA user_version with immutable ordered migrations, active generation fingerprint, and compatibility evidence for policy versions cited by retained reports.
Settings: foreign_keys=ON, journal_mode=WAL, synchronous=FULL, bounded busy_timeout.
Write boundary: BEGIN IMMEDIATE for Retain, changed Restate, Delete, idempotency, recovery receipts, restore events, and migration metadata.
Protection: directories 0700; database, WAL, SHM, CURRENT, lock, backup, manifest, and recognized candidate artifacts 0600 where supported.
Never persisted: dated actual members, raw merchant text, canonical transaction payload, producer cursor, private corpus row, PolicyValidationReceipt, arbitrary formula, report list payload, or upstream state replica.
