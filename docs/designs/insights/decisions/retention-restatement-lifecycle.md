# Append-only Report Snapshots with replay-safe Restatement and leaf deletion

**Ref Code:** DD-INSIGHTS-RETENTION-RESTATEMENT-LIFECYCLE

## Description

Preserve exactly what was shown while supporting explicit retention, correction-based comparison, dependency-safe deletion, and stable retries.

## Decision

Generate writes nothing. Retain resolves idempotency before producer reads, generates internally, and atomically appends one immutable snapshot and outcome reference. Restate loads one predecessor, generates current evidence through the same compiler, and appends one child plus predecessor link when provenance, policy, schema, or semantic content changes; identical results return No Change. Delete applies RESTRICT to referenced snapshots, removes one unreferenced leaf payload and outgoing link, and appends one metadata-only Deletion Event. Same key and request replay prior outcomes; changed input conflicts.

## Rationale

In-place refresh destroys auditability. Storing arbitrary caller reports breaks provenance. Cascading deletion corrupts surviving Restatement chains. Event sourcing would add replay and projection complexity beyond the moderate budget. Immutable append plus explicit links and metadata-only deletion keeps every accepted lifecycle observable and atomic.

## Alternatives

A: update a current report in place, rejected because corrections erase what was shown. B: retain caller-authored report payloads, rejected because provenance cannot be trusted. C: event-source every report calculation, rejected as excessive complexity. D: append immutable generated snapshots, explicit predecessor links, No Change outcomes, and RESTRICT leaf deletion, chosen.

## Consequences

Snapshot IDs are opaque ULIDs distinct from deterministic report IDs. Request hashes include operation, version, actor, reason, target, selectors, and safe path identity. If a retained outcome is later deleted, retry returns metadata-only Deleted and never recreates content. No automatic expiry occurs. Existing backups remain point-in-time artifacts.
