## cqrs

| Pattern | Zone | Purpose |
|---------|------|---------|
| [Command Pattern — NxGN Actions](api-commands.md) | api | **AI Summary**: Commands are write operations that modify the database. Production command constructors use IDbContextFactory<ActionsDbContext> and every DbContext-backed command execution method accepts optional ActionsDbContext? dbContext after CancellationToken so commands can run independently or participate in a caller-owned transaction. Save commands use the upsert pattern, delete and lifecycle commands return CommandResult variants, expected domain failures return structured CommandError, and transactional audit rows receive the shared context. |
| [Query Pattern — NxGN Actions](api-queries.md) | api | **AI Summary**: Queries are read-only database operations that use IDbContextFactory<ActionsDbContext> for production DI and accept an optional ActionsDbContext? dbContext parameter after CancellationToken so they can run independently or participate in a caller-owned context/transaction. Each query is a single-purpose class with one ExecuteAsync method. Grid-list queries apply deterministic filtering, sorting, and paging; lookup queries project lightweight DTOs; single-entity queries load the aggregate needed by the endpoint. Direct scoped ActionsDbContext injection is forbidden in production query constructors. |
