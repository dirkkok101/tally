## Purpose

**AI Summary**: The DTOMapperDataContext pattern pre-loads multiple data types in parallel for DTOMapper classes that need 2+ additional data sources beyond the entity. A `DTOMapperDataContextService` orchestrates parallel loading via `Task.WhenAll`, returning a POCO that the DI-registered `DTOMapper` consumes. | Additional Data Types | Pattern | Example |
|-----------------------|---------|---------|
| 0 (entity only) | Simple mapper | `dtoMapper.Map(action, reqLangId, defLangId)` — entity with eager-loaded navigation props |
| 1 additional | Direct parameter | `dtoMapper.Map(action, reqLangId, defLangId, workflowStates)` — entity + one extra type passed directly |
| 2+ additional | **DTOMapperDataContext** | `dtoMapper.Map(action, reqLangId, defLangId, context)` — entity + escalation rules + compliance data |

## DTOMapperDataContext POCO

Simple class holding pre-loaded additional data:

```csharp
// Features/Actions/Shared/Mappers/ActionDTOMapperDataContext.cs

public class ActionDTOMapperDataContext
{
    public required Dictionary<Guid, EscalationRule> EscalationRuleMap { get; init; }
    public required Dictionary<Guid, ComplianceProfile> ComplianceProfileMap { get; init; }
}
```

### Property Conventions

- **Use `required`** — ensures all data is provided at construction
- **Use `init`** — makes properties immutable after construction
- **One property per data source** — each query result gets its own property
- **Entity is NOT in DTOMapperDataContext** — entity is passed separately to the DTOMapper method
- **Hold raw entities or computed data** — the DTOMapper transforms to DTO shapes (e.g., `NamedDTO`, `EnumDTO`)

## DTOMapperDataContextService

Orchestrates parallel loading:

```csharp
// Features/Actions/Shared/Mappers/ActionDTOMapperDataContextService.cs

public class ActionDTOMapperDataContextService(
    IDbContextFactory<ActionsDbContext> dbContextFactory,
    ILogger<ActionDTOMapperDataContextService> logger)
{
    public async Task<ActionDTOMapperDataContext> GetAsync(
        Guid actionId,
        CancellationToken ct)
    {
        logger.LogDebug("Loading ActionDTOMapperDataContext for action {ActionId}",
            actionId);

        await using var dbContext = await dbContextFactory.CreateDbContextAsync(ct);

        // Start all queries in parallel
        var getEscalationRulesTask = dbContext.EscalationRules
            .AsNoTracking()
            .ToListAsync(ct);
        var getComplianceProfilesTask = dbContext.ComplianceProfiles
            .AsNoTracking()
            .ToListAsync(ct);

        await Task.WhenAll(getEscalationRulesTask, getComplianceProfilesTask);

        return new ActionDTOMapperDataContext
        {
            EscalationRuleMap = (await getEscalationRulesTask).ToDictionary(r => r.Id),
            ComplianceProfileMap = (await getComplianceProfilesTask).ToDictionary(p => p.Id)
        };
    }
}
```

### Service Conventions

- **Primary constructor** — inject `IDbContextFactory<ActionsDbContext>` and any additional services
- **Task variables first** — start all queries before any `await` (except the DbContext creation)
- **`Task.WhenAll`** — wait for all queries simultaneously
- **Return the POCO** — don't expose query details to the DTOMapper
- **Log at Debug level** — context loading is diagnostic, not a business event

## DI-Registered DTOMapper with DTOMapperDataContext

The DTOMapper is a DI-registered class that receives the entity and context as parameters. It is a pure transformer — no database access:

```csharp
// Features/Actions/Shared/Mappers/ActionDTOMapper.cs

public class ActionDTOMapper(TranslationService translationService)
{
    public ActionDTO Map(
        ActionEntity entity,
        Guid requestLanguageId,
        Guid defaultLanguageId,
        ActionDTOMapperDataContext context)
    {
        var translation = translationService.GetEntityTranslation(
            entity, requestLanguageId, defaultLanguageId);

        return new ActionDTO
        {
            Id = entity.Id,
            Name = translation.Name,
            Description = translation.Description,
            ReferenceNumber = entity.ReferenceNumber,
            Status = new EnumDTO((int)entity.Status, entity.Status.ToString()),
            Priority = new EnumDTO((int)entity.Priority, entity.Priority.ToString()),
            DueDate = entity.DueDate,
            CompletedDate = entity.CompletedDate,
            Version = entity.Version,
            CreatedDate = entity.CreatedDate,
            UpdatedDate = entity.UpdatedDate,

            // Navigation property — eager-loaded on entity
            WorkflowDefinition = new NamedDTO
            {
                Id = entity.WorkflowDefinition.Id,
                Name = entity.WorkflowDefinition.Code,
            },

            // From DTOMapperDataContext — additional data loaded in parallel
            Evidence = entity.Evidence
                .Select(e => new ActionEvidenceDTO
                {
                    Id = e.Id,
                    FileName = e.FileName,
                })
                .ToList(),
        };
    }

    public ActionGridItemDTO MapGridItem(
        ActionEntity entity,
        Guid requestLanguageId,
        Guid defaultLanguageId,
        ActionDTOMapperDataContext context)
    {
        var translation = translationService.GetEntityTranslation(
            entity, requestLanguageId, defaultLanguageId);

        return new ActionGridItemDTO
        {
            Id = entity.Id,
            Name = translation.Name,
            ReferenceNumber = entity.ReferenceNumber,
            StatusName = entity.Status.ToString(),
            PriorityName = entity.Priority.ToString(),
            WorkflowName = entity.WorkflowDefinition?.Code ?? string.Empty,
            DueDate = entity.DueDate,
            EvidenceCount = entity.Evidence.Count,
            CreatedDate = entity.CreatedDate,
        };
    }
}
```

## Endpoint Usage

### Get Endpoint

```csharp
// Features/Actions/Get/GetActionEndpoint.cs

public sealed class GetActionEndpoint(
    GetActionQuery getActionQuery,
    ActionDTOMapperDataContextService dataContextService,
    ActionDTOMapper dtoMapper)
    : TenantEndpointWithoutRequest<ActionDTO>
{
    public override void Configure()
    {
        Get("/api/v1/actions/{id}");
        Policies(ActionConstants.PolicyNames.ActionViewer);
    }

    protected override async Task HandleValidatedRequestAsync(CancellationToken ct)
    {
        var id = Route<Guid>("id");

        // 1. Load entity via query
        var action = await getActionQuery.ExecuteAsync(id, ct);
        if (action is null) { await Send.NotFoundAsync(ct); return; }

        // 2. Load additional context data (parallel queries)
        var context = await dataContextService.GetAsync(action.Id, ct);

        // 3. Map via DI-registered DTOMapper
        await Send.OkAsync(
            dtoMapper.Map(action, RequestLanguageId, DefaultLanguageId, context), ct);
    }
}
```

### GetGridList Endpoint

The same DTOMapperDataContext is shared across Get and GetGridList endpoints:

```csharp
// Features/Actions/GetGridList/GetActionGridListEndpoint.cs

public sealed class GetActionGridListEndpoint(
    GetActionsQuery getActionsQuery,
    GetActionsCountQuery getActionsCountQuery,
    ActionDTOMapperDataContextService dataContextService,
    ActionDTOMapper dtoMapper)
    : TenantEndpoint<PagedRequest, GridListResponse<ActionGridItemDTO>>
{
    public override void Configure()
    {
        Post("/api/v1/actions/grid-list");
        Policies(ActionConstants.PolicyNames.ActionViewer);
    }

    protected override async Task HandleValidatedRequestAsync(
        PagedRequest req, CancellationToken ct)
    {
        var parameters = new ActionQueryParameters()
            .WithSearch(req.Search)
            .WithStatus(req.Status)
            .WithPagination(
                skip: (req.Page - 1) * req.PageSize,
                take: req.PageSize);

        var dataTask = getActionsQuery.ExecuteAsync(parameters, ct);
        var countTask = getActionsCountQuery.ExecuteAsync(parameters, ct);
        await Task.WhenAll(dataTask, countTask);

        // DTOMapperDataContext loaded once, used for all items
        var context = await dataContextService.GetAsync(ct);

        var items = (await dataTask)
            .Select(a => dtoMapper.MapGridItem(a, RequestLanguageId, DefaultLanguageId, context))
            .ToList();

        await Send.OkAsync(
            new GridListResponse<ActionGridItemDTO>(
                items, await countTask, req.Page, req.PageSize),
            ct);
    }
}
```

## Naming Convention

| Component | Name | File |
|-----------|------|------|
| DTOMapperDataContext POCO | `{Entity}DTOMapperDataContext` | `{Entity}DTOMapperDataContext.cs` |
| DTOMapperDataContext Service | `{Entity}DTOMapperDataContextService` | `{Entity}DTOMapperDataContextService.cs` |
| DTOMapper class | `{Entity}DTOMapper` | `{Entity}DTOMapper.cs` |

**Why?** The DTOMapperDataContext belongs to the DTOMapper, not to a specific endpoint. This naming ensures:
- Clear ownership — the context serves mapping, not a specific operation
- Files co-locate with the DTOMapper in `Shared/Mappers/`
- Reusability across Get, GetGridList, and other read endpoints
- Alignment with Capstone naming conventions

### Correct vs Wrong Naming

| Correct | Wrong | Why |
|---------|-------|-----|
| `ActionDTOMapperDataContext` | `GetActionDataContext` | Context serves all DTOMapper methods, not one endpoint |
| `ActionDTOMapperDataContextService` | `ActionMappingContextService` | Aligns with Capstone naming and DTOMapper class pattern |
| `ActionDTOMapperDataContext` | `ActionContext` | Too generic — could be confused with auth or request context |

## Correct vs Wrong: Common Mistakes

### DTOMapper receives context / Mapper with injected queries

```csharp
// CORRECT — DI-registered DTOMapper, pure transformer
public class ActionDTOMapper(TranslationService translationService)
{
    public ActionDTO Map(
        ActionEntity entity,
        Guid requestLanguageId,
        Guid defaultLanguageId,
        ActionDTOMapperDataContext context)
    {
        var translation = translationService.GetEntityTranslation(
            entity, requestLanguageId, defaultLanguageId);

        return new ActionDTO
        {
            Name = translation.Name,
            WorkflowDefinition = new NamedDTO
            {
                Id = entity.WorkflowDefinition.Id,
                Name = entity.WorkflowDefinition.Code,
            },
        };
    }
}

// WRONG — DTOMapper with injected queries
public class ActionDTOMapper(GetEscalationRulesQuery getEscalationRulesQuery)
{
    public async Task<ActionDTO> MapAsync(ActionEntity entity, CancellationToken ct)
    {
        var rules = await getEscalationRulesQuery.ExecuteAsync(...); // Mapper must NEVER query
        return new ActionDTO { ... };
    }
}
```

### Entity passed separately / Entity inside DTOMapperDataContext

```csharp
// CORRECT — Entity is a parameter to the DTOMapper method
public ActionDTO Map(ActionEntity entity, Guid requestLanguageId, Guid defaultLanguageId, ActionDTOMapperDataContext context) { ... }

// WRONG — Entity bundled into context
public class ActionDTOMapperDataContext
{
    public required ActionEntity Entity { get; init; }       // WRONG — entity is NOT context
    public required Dictionary<Guid, EscalationRule> RuleMap { get; init; }
}
```

### DTOMapperDataContext for 2+ types / DTOMapperDataContext for 1 type

```csharp
// CORRECT — 1 additional type? Pass it directly as a parameter
public WorkflowDefinitionDTO Map(WorkflowDefinition entity, Guid requestLanguageId, Guid defaultLanguageId, IList<WorkflowState> states)
{
    return new WorkflowDefinitionDTO { ... };
}

// WRONG — DTOMapperDataContext overkill for a single additional type
public class WorkflowDTOMapperDataContext
{
    public required List<WorkflowState> AllStates { get; init; }  // Only 1 type — no context needed
}
```

### Parallel loading with Task.WhenAll / Sequential awaits

```csharp
// CORRECT — Start all queries, then await together
var getEscalationRulesTask = dbContext.EscalationRules.ToListAsync(ct);
var getComplianceProfilesTask = dbContext.ComplianceProfiles.ToListAsync(ct);
await Task.WhenAll(getEscalationRulesTask, getComplianceProfilesTask);

// WRONG — Sequential awaits waste time
var rules = await dbContext.EscalationRules.ToListAsync(ct);             // blocks
var profiles = await dbContext.ComplianceProfiles.ToListAsync(ct);       // waits for rules to finish
```

## Comparison of All Mapper Data Patterns

| Aspect | Simple | Direct Parameter | DTOMapperDataContext |
|--------|--------|-------------------|----------------------|
| **Extra data types** | 0 | 1 | 2+ |
| **Entity loaded by** | Endpoint | Endpoint | Endpoint |
| **Extra data loaded by** | N/A | Endpoint | DTOMapperDataContextService |
| **Mapper signature** | `dtoMapper.Map(entity, reqLang, defLang)` | `dtoMapper.Map(entity, reqLang, defLang, extra)` | `dtoMapper.Map(entity, reqLang, defLang, context)` |
| **Parallel loading** | N/A | `Task.WhenAll` in endpoint | `Task.WhenAll` in service |
| **Files in Shared/Mappers/** | 1 | 1 | 3 |

## Rules

### MUST

1. **Entity is loaded in the endpoint**, not the DTOMapperDataContextService
2. **DTOMapperDataContext holds only additional data**, not the entity itself
3. **Use `required init`** on all DTOMapperDataContext properties
4. **Use `Task.WhenAll`** for parallel loading in the service
5. **Use DI-registered DTOMapper class** for mapping — `dtoMapper.Map(entity, requestLanguageId, defaultLanguageId, context)`
6. **Only use DTOMapperDataContext when 2+ additional data types are needed** — 1 extra type uses the Direct Parameter pattern

### SHOULD

1. **Name context `{Entity}DTOMapperDataContext`** and service `{Entity}DTOMapperDataContextService`
2. **Co-locate files** with the DTOMapper in `Shared/Mappers/`
3. **Log at Debug level** in the service for context loading
4. **Share DTOMapperDataContext between `Map()` and `MapGridItem()`** — load once, map many
5. **Use `IDbContextFactory<ActionsDbContext>`** in the service for database queries

### MUST NOT

1. **Inject queries or DbContext into the DTOMapper** — queries belong in the service
2. **Put the entity in the DTOMapperDataContext** — pass it separately as a parameter to the DTOMapper
3. **Create DTOMapperDataContext for a single additional type** — use a direct parameter instead

```csharp
        var rules = await getEscalationRulesQuery.ExecuteAsync(...); // Mapper must NEVER query
        return new ActionDTO { ... };
    }
}
```

### Correct vs Wrong: Common Mistakes Example 2

```csharp
// CORRECT — Entity is a parameter to the DTOMapper method
public ActionDTO Map(ActionEntity entity, Guid requestLanguageId, Guid defaultLanguageId, ActionDTOMapperDataContext context) { ... }

// WRONG — Entity bundled into context
public class ActionDTOMapperDataContext
{
    public required ActionEntity Entity { get; init; }       // WRONG — entity is NOT context
    public required Dictionary<Guid, EscalationRule> RuleMap { get; init; }
}
```

### Correct vs Wrong: Common Mistakes Example 3

```csharp
// CORRECT — 1 additional type? Pass it directly as a parameter
public WorkflowDefinitionDTO Map(WorkflowDefinition entity, Guid requestLanguageId, Guid defaultLanguageId, IList<WorkflowState> states)
{
    return new WorkflowDefinitionDTO { ... };
}

// WRONG — DTOMapperDataContext overkill for a single additional type
public class WorkflowDTOMapperDataContext
{
    public required List<WorkflowState> AllStates { get; init; }  // Only 1 type — no context needed
}
```

### Correct vs Wrong: Common Mistakes Example 4

```csharp
// CORRECT — Start all queries, then await together
var getEscalationRulesTask = dbContext.EscalationRules.ToListAsync(ct);
var getComplianceProfilesTask = dbContext.ComplianceProfiles.ToListAsync(ct);
await Task.WhenAll(getEscalationRulesTask, getComplianceProfilesTask);

// WRONG — Sequential awaits waste time
var rules = await dbContext.EscalationRules.ToListAsync(ct);             // blocks
var profiles = await dbContext.ComplianceProfiles.ToListAsync(ct);       // waits for rules to finish
```

## Rules

### MUST

- **Entity is loaded in the endpoint**, not the DTOMapperDataContextService
- **DTOMapperDataContext holds only additional data**, not the entity itself
- **Use `required init`** on all DTOMapperDataContext properties
- **Use `Task.WhenAll`** for parallel loading in the service
- **Use DI-registered DTOMapper class** for mapping — `dtoMapper.Map(entity, requestLanguageId, defaultLanguageId, context)`
- **Only use DTOMapperDataContext when 2+ additional data types are needed** — 1 extra type uses the Direct Parameter pattern

### MUST NOT

- **Inject queries or DbContext into the DTOMapper** — queries belong in the service
- **Put the entity in the DTOMapperDataContext** — pass it separately as a parameter to the DTOMapper
- **Create DTOMapperDataContext for a single additional type** — use a direct parameter instead

### SHOULD

- **Name context `{Entity}DTOMapperDataContext`** and service `{Entity}DTOMapperDataContextService`
- **Co-locate files** with the DTOMapper in `Shared/Mappers/`
- **Log at Debug level** in the service for context loading
- **Share DTOMapperDataContext between `Map()` and `MapGridItem()`** — load once, map many
- **Use `IDbContextFactory<ActionsDbContext>`** in the service for database queries
