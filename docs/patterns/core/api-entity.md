## Purpose

**AI Summary**: Domain model base classes, interfaces, and entity conventions for the Actions platform. Covers `Entity`, `TrackedEntity`, `ITenantEntity`, `ITranslatedEntity<T>`, `ITranslation`, `EntityTranslation`, `ISoftDeletable`, `IVersioned`, primary keys, collections, foreign keys, enum properties, and constructors. ### ITenantEntity

```csharp
// Data/Entities/ITenantEntity.cs
public interface ITenantEntity
{
    Guid TenantId { get; set; }
}
```

Entities scoped to a single tenant implement `ITenantEntity`. RLS policies filter by `TenantId` at the database level -- application code does not filter by tenant.

### ISoftDeletable

```csharp
// Data/Entities/ISoftDeletable.cs
public interface ISoftDeletable
{
    bool IsDeleted { get; set; }
    DateTime? DeletedDate { get; set; }
    Guid? DeletedById { get; set; }
}
```

Entities that should never be physically deleted implement `ISoftDeletable`. Delete commands set these fields instead of removing rows. Global query filters in EF Core exclude soft-deleted records by default.

### IVersioned

```csharp
// Data/Entities/IVersioned.cs
public interface IVersioned
{
    int Version { get; set; }
}
```

Entities that need optimistic concurrency control implement `IVersioned`. The `Version` field is configured as a concurrency token in EF Core. Save commands check the version to prevent conflicting updates.

### ITranslatedEntity / ITranslation

For entities requiring multi-language support:

```csharp
// Data/Entities/ITranslatedEntity.cs
public interface ITranslatedEntity<T> where T : ITranslation
{
    Guid Id { get; set; }
    IList<T> Translations { get; set; }
}

// Data/Entities/ITranslation.cs
public interface ITranslation
{
    string Name { get; set; }
    string? Description { get; set; }
    Guid LanguageId { get; set; }
}

// Data/Entities/EntityTranslation.cs
public abstract class EntityTranslation : TrackedEntity, ITenantEntity, ITranslation
{
    public string Name { get; set; } = string.Empty;
    public string? Description { get; set; }
    public Guid LanguageId { get; set; }
    public Language Language { get; set; } = null!;
    public Guid TenantId { get; set; }
}
```

Entities that need translation implement `ITranslatedEntity<T>` where `T` extends `EntityTranslation`. Each translation record carries a `LanguageId` FK and tenant scope. The `TranslationService` handles fallback resolution (request language -> default -> first available). Actions supports translations from day one.

## Entity Conventions

### Primary Keys

- All entities use `Guid Id`
- New IDs: `Guid.CreateVersion7()` (time-ordered UUIDs)

### Collections

Always initialize to empty:

```csharp
public ICollection<WorkflowState> States { get; set; } = [];
public ICollection<ActionEvidence> Evidence { get; set; } = [];
```

### Foreign Keys

Required FK -- both ID and navigation with `= null!`:

```csharp
public Guid WorkflowDefinitionId { get; set; }
public WorkflowDefinition WorkflowDefinition { get; set; } = null!;
```

Optional FK -- nullable ID and nullable navigation:

```csharp
public Guid? ParentActionId { get; set; }
public ActionEntity? ParentAction { get; set; }
```

### Enum Properties ([ADR-0004](../../adr/0004-enum-over-string-constants-for-status-fields.md))

All status, kind, and mode fields use C# enums -- never `static class` with `const string`. Enums provide compile-time safety, exhaustive `switch` checking, and `HasConversion<string>()` in EF Core for readable database values.

```csharp
// Correct — C# enum
public ActionStatus Status { get; set; } = ActionStatus.Open;
public EscalationSeverity Severity { get; set; } = EscalationSeverity.Medium;
public WorkflowTriggerType TriggerType { get; set; } = WorkflowTriggerType.Manual;

// Wrong — static string constants
public string Status { get; set; } = ActionStatuses.Open;  // violates ADR-0004
```

Define enums in the Contracts project so DTOs can reference them for `EnumDTO` mapping:

```csharp
// Nxgn.Actions.Contracts/Actions/ActionStatus.cs
public enum ActionStatus
{
    Open = 0,
    InProgress = 1,
    UnderReview = 2,
    Closed = 3,
    Overdue = 4
}

// Nxgn.Actions.Contracts/EscalationRules/EscalationSeverity.cs
public enum EscalationSeverity
{
    Low = 0,
    Medium = 1,
    High = 2,
    Critical = 3
}

// Nxgn.Actions.Contracts/Workflows/WorkflowTriggerType.cs
public enum WorkflowTriggerType
{
    Manual = 0,
    Automatic = 1,
    Scheduled = 2
}
```

### Constructors

Entities use the default parameterless constructor (class-level properties with initializers). Primary constructors are for services, commands, queries, and mappers -- not entities.

### JsonDocument for Flexible Data

Use `JsonDocument` for semi-structured fields that vary per tenant or don't warrant dedicated columns:

```csharp
public JsonDocument Configuration { get; set; } = JsonDocument.Parse("{}");
public JsonDocument Metadata { get; set; } = JsonDocument.Parse("{}");
```

These require custom value converters in EF configuration (see [EF Configuration](ef-configuration.md)).

## Entity Examples

### Aggregate Root with Translations and Soft Delete

```csharp
// Data/Entities/ActionEntity.cs
public class ActionEntity : TrackedEntity, ITenantEntity, ISoftDeletable, IVersioned
{
    public Guid TenantId { get; set; }
    public string ReferenceNumber { get; set; } = string.Empty;
    public ActionStatus Status { get; set; } = ActionStatus.Open;
    public ActionPriority Priority { get; set; } = ActionPriority.Medium;
    public DateTime? DueDate { get; set; }
    public DateTime? CompletedDate { get; set; }
    public Guid? AssignedToId { get; set; }
    public JsonDocument Metadata { get; set; } = JsonDocument.Parse("{}");

    // IVersioned
    public int Version { get; set; }

    // ISoftDeletable
    public bool IsDeleted { get; set; }
    public DateTime? DeletedDate { get; set; }
    public Guid? DeletedById { get; set; }

    // Workflow
    public Guid WorkflowDefinitionId { get; set; }
    public WorkflowDefinition WorkflowDefinition { get; set; } = null!;
    public Guid? CurrentStateId { get; set; }
    public WorkflowState? CurrentState { get; set; }

    // Navigation properties
    public ICollection<ActionEvidence> Evidence { get; set; } = [];
    public ICollection<ActionConsultation> Consultations { get; set; } = [];
    public ICollection<ActionDeadline> Deadlines { get; set; } = [];
}
```
