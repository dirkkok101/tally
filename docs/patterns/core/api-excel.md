# Excel Import/Export — NXGN Actions

> Generated from the lex graph. Do not edit this file as source of truth; update graph entities and re-export.

**Ref Code:** PAT-CORE-API-EXCEL

## Purpose

**Scope**: This document describes the patterns for Excel download (export) and upload (import) of entity data. Based on Capstone's GemBox.Spreadsheet patterns, adapted for Actions' vertical slice structure.

## Overview

Excel operations follow a 5-file pattern per feature:

| File | Location | Purpose |
|------|----------|---------|
| `{Entity}ExcelColumnDefs.cs` | `Features/{Entity}/Shared/Excel/` | Static column definitions |
| `{Entity}ExcelExporter.cs` | `Features/{Entity}/Shared/Excel/` | Entity → Excel bytes |
| `{Entity}ExcelExporterContext.cs` | `Features/{Entity}/Shared/Excel/` | Pre-loaded data for export (optional) |
| `{Entity}ExcelImporter.cs` | `Features/{Entity}/Shared/Excel/` | Excel rows → DTOs with validation |
| `{Entity}ExcelImporterContext.cs` | `Features/{Entity}/Shared/Excel/` | Pre-loaded lookup maps for import |

Plus two endpoints and their supporting files:

| File | Location | Purpose |
|------|----------|---------|
| `Download{Entity}ExcelEndpoint.cs` | `Features/{Entity}/DownloadExcel/` | Export endpoint (returns file) |
| `Upload{Entity}ExcelEndpoint.cs` | `Features/{Entity}/UploadExcel/` | Import endpoint (accepts file) |
| `Upload{Entity}ExcelRequest.cs` | `Features/{Entity}/UploadExcel/` | Request with IFormFile |
| `Upload{Entity}ExcelRequestValidator.cs` | `Features/{Entity}/UploadExcel/` | Validates file is present |
| `Upload{Entity}ExcelResponse.cs` | `Nxgn.Actions.Contracts/{Entity}/` | Extends ExcelUploadResult<T> |

- `ExcelColumnDef(string displayName)` — auto-derives PascalCase key from display name
- `ExcelColumnGroupDef(string groupName, params ExcelColumnDef[] columns)` — groups columns under a header
- `All` property iterates all columns in display order (used by both exporter and importer)

## Excel Exporter

The exporter is a DI-registered class that transforms entities to Excel bytes. It never
queries the database — all data is passed in.

```csharp
public class EscalationRuleExcelExporter(
    TranslationService translationService,
    ILogger<EscalationRuleExcelExporter> logger)
{
    public byte[] GenerateExcel(
        IList<EscalationRule> entities,
        Guid requestLanguageId,
        Guid defaultLanguageId)
    {
        var workbook = new ExcelFile();
        var worksheet = workbook.Worksheets.Add("Escalation Rules");

        // Header row
        var column = 0;
        foreach (var col in EscalationRuleExcelColumnDefs.All)
            worksheet.Cells[0, column++].Value = col.DisplayName;

        // Data rows
        for (var row = 0; row < entities.Count; row++)
        {
            var entity = entities[row];
            var name = translationService.GetEntityTranslation(
                entity.Translations, requestLanguageId, defaultLanguageId);

            column = 0;
            worksheet.Cells[row + 1, column++].Value = name?.Name ?? string.Empty;
            worksheet.Cells[row + 1, column++].Value = entity.Priority;
            worksheet.Cells[row + 1, column++].Value = entity.ThresholdDays;
            worksheet.Cells[row + 1, column++].Value = entity.Tier;
            worksheet.Cells[row + 1, column++].Value = entity.NotificationTarget;
        }

        using var stream = new MemoryStream();
        workbook.Save(stream, SaveOptions.XlsxDefault);
        return stream.ToArray();
    }
}
```

**Key conventions:**
- Inject `TranslationService` for translatable field resolution
- `GenerateExcel` receives entities and language IDs — never queries DB
- Returns `byte[]` (MemoryStream → ToArray)
- Header row from `ExcelColumnDefs.All`
- Cell-by-cell writing with `column++` pattern
- For complex exports needing additional data, use an `ExporterContext` POCO + `ExporterContextService`

## Excel Importer

The importer parses Excel rows into DTOs with per-row validation. It never saves to
the database — the calling endpoint passes the result to the SaveCommand.

```csharp
public class EscalationRuleExcelImporter(
    EscalationRuleExcelImporterContextService contextService,
    ILogger<EscalationRuleExcelImporter> logger)
{
    public async Task<ExcelUploadResult<EscalationRuleDTO>> MapFromExcelFile(
        ExcelFile excelFile,
        Guid requestLanguageId,
        Guid defaultLanguageId,
        CancellationToken ct)
    {
        var result = new ExcelUploadResult<EscalationRuleDTO>();
        var context = await contextService.LoadAsync(ct);

        var worksheet = excelFile.Worksheets[0];
        if (worksheet.Rows.Count < 2)
        {
            result.UploadErrors.Add(new ExcelUploadError
            {
                RowIndex = 0, ColumnIndex = 0,
                ErrorMessage = "No data rows found"
            });
            return result;
        }

        // Build column index from header row
        var columnIndex = new Dictionary<string, int>();
        foreach (var col in EscalationRuleExcelColumnDefs.All)
        {
            var idx = FindColumnIndex(worksheet, col.DisplayName);
            if (idx >= 0)
                columnIndex[col.Key] = idx;
        }

        // Parse data rows
        for (var rowIdx = 1; rowIdx < worksheet.Rows.Count; rowIdx++)
        {
            var row = worksheet.Rows[rowIdx];
            var hasErrors = false;
            var dto = new EscalationRuleDTO { Id = Guid.Empty };

            // Required: Name
            var name = row.Cells.GetCellSafe(
                columnIndex.GetValueOrDefault("Name", -1))
                .GetStringValue();
            if (string.IsNullOrWhiteSpace(name))
            {
                result.UploadErrors.Add(new ExcelUploadError
                {
                    RowIndex = rowIdx, ColumnIndex = 0,
                    ErrorMessage = "Name is required"
                });
                hasErrors = true;
            }
            else
            {
                dto.Name = name;
            }

            // ... parse remaining columns ...

            if (!hasErrors)
                result.Items.Add(dto);
        }

        return result;
    }
}
```

**Key conventions:**
- Returns `ExcelUploadResult<DTO>` with Items (valid) + UploadErrors (per-cell)
- All DTOs get `Id = Guid.Empty` (create mode — the SaveCommand handles upsert via EntityMapper)
- Context service pre-loads lookup maps for validation (e.g., valid workflow names, priority values)
- Never saves to DB — the endpoint handles that
- Errors are per-row/per-column with descriptive messages

## Download Endpoint

```csharp
public class DownloadEscalationRuleExcelEndpoint(
    GetEscalationRulesQuery query,
    EscalationRuleExcelExporter exporter,
    ILogger<DownloadEscalationRuleExcelEndpoint> logger)
    : TenantEndpointWithoutRequest
{
    public override void Configure()
    {
        Post("/api/v1/admin/escalation-rules/download-excel");
        Description(x => x.WithName("DownloadEscalationRuleExcel"));
    }

    protected override async Task HandleValidatedRequestAsync(CancellationToken ct)
    {
        // 1. Load all entities for tenant
        var parameters = new EscalationRuleQueryParameters();
        var entities = await query.ExecuteAsync(parameters, ct);

        // 2. Generate Excel
        var bytes = exporter.GenerateExcel(
            entities, RequestLanguageId, DefaultLanguageId);

        // 3. Return file
        await SendBytesAsync(
            bytes,
            "escalation-rules.xlsx",
            "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
            cancellation: ct);
    }
}
```

**Key conventions:**
- `TenantEndpointWithoutRequest` (no request body)
- Route: `POST /api/v1/{feature}/download-excel`
- Three-step pattern: load entities → generate Excel → send bytes
- For complex exports, add context loading step between load and generate

## Upload Endpoint

```csharp
public class UploadEscalationRuleExcelEndpoint(
    EscalationRuleExcelImporter importer,
    SaveEscalationRuleCommand saveCommand,
    ILogger<UploadEscalationRuleExcelEndpoint> logger)
    : TenantEndpoint<UploadEscalationRuleExcelRequest,
        UploadEscalationRuleExcelResponse>
{
    public override void Configure()
    {
        Post("/api/v1/admin/escalation-rules/upload-excel");
        AllowFileUploads();
        Description(x => x.WithName("UploadEscalationRuleExcel"));
    }

    protected override async Task HandleValidatedRequestAsync(
        UploadEscalationRuleExcelRequest req, CancellationToken ct)
    {
        // 1. Load Excel file
        await using var stream = req.File!.OpenReadStream();
        var excelFile = ExcelFile.Load(stream, LoadOptions.XlsxDefault);

        // 2. Parse rows into DTOs
        var importResult = await importer.MapFromExcelFile(
            excelFile, RequestLanguageId, DefaultLanguageId, ct);

        // 3. If parsing succeeded, save via batch command
        if (importResult.IsValid)
        {
            await saveCommand.ExecuteAsync(
                importResult.Items.ToList(),
                UserId, RequestLanguageId, DefaultLanguageId, ct);
        }

        // 4. Return result (items + errors)
        var response = new UploadEscalationRuleExcelResponse
        {
            Items = importResult.Items,
            UploadErrors = importResult.UploadErrors,
            UploadWarnings = importResult.UploadWarnings
        };

        await SendOkAsync(response, ct);
    }
}
```

## Decision Tree: Does This Feature Need Excel?

```
Does the feature need bulk import from spreadsheets?
├── YES → Add UploadExcel endpoint + Importer + ImporterContext
│         (batch EntityMapper + SaveCommand are already batch-primary)
├── NO  → Skip upload files
│
Does the feature need data export to spreadsheets?
├── YES → Add DownloadExcel endpoint + Exporter (+ ExporterContext if needed)
├── NO  → Skip download files
│
Does the feature need both?
├── YES → Add all 5 Excel files + 2 endpoints
│         (ExcelColumnDefs shared between exporter and importer)
```
