# Capture Page Pattern — NXGN Actions Web

## Purpose

AI Summary: Capture pages for aggregate roots are routed create/edit pages that load foreign-key lookup data in parallel with the aggregate root, stitch the editable aggregate client-side, and submit one Save request through the feature service. The API maps the full aggregate and saves it in one session. Use nxgn-capture-page-title, signals, feature-colocated services, inline errors, and canDeactivate protection.

## Aggregate Root Edit/Create Standard

All admin create/edit pages for aggregate roots must follow the Actions/Identity aggregate-root pattern used by Users, Roles, and Translation Keys. The list page navigates to a routed capture page. The capture component loads all foreign-key lookup elements in parallel with the aggregate root when editing. It stitches those lookups and the aggregate DTO into local signal state, including child collections rendered with nxgn-data-grid when needed. Save builds one SaveXRequest for the whole aggregate and calls the feature service save method. The API endpoint maps the full request to entities and commits the aggregate in one database session. Create mode uses EMPTY_GUID or the module's documented create sentinel. Edit mode includes rowVersion or equivalent concurrency state when the aggregate supports concurrency.

## Template Structure

Key structural elements, using `ActionCaptureComponent` as the canonical example:

1. **Wrapper div** with `[class.d-none]="childActive()"` — hides parent when a child route is active (aggregate pages only)
2. **`nxgn-capture-page-title`** — toolbar with Save/Cancel and optional domain command buttons
3. **Inline saving indicator** — alert with spinner (only while saving)
4. **Inline error message** — alert-danger (only when errorMessage is set)
5. **Loading spinner** — centered spinner while loading entity
6. **Card sections** — Bootstrap cards for form fields, embedded lists, read-only info
7. **`<router-outlet>`** — for aggregate child routes (only when entity has child routes)

```html
<!-- Hide parent content when a child capture route is active -->
<div [class.d-none]="childActive()">
  <nxgn-capture-page-title
    [title]="'action_capture_title' | translate"
    [newRecord]="!isEditMode()"
    [isValid]="isFormValid()"
    [addPrefix]="'common_new' | translate"
    (save)="onSave()"
    (cancel)="onCancel()"
  >
    <!-- Domain command buttons (edit mode only, non-system entities) -->
    @if (isEditMode() && !isProtected && action()) {
      <button
        custom-buttons
        type="button"
        class="btn btn-sm"
        [class.btn-outline-danger]="action()?.status?.name === 'Active'"
        [class.btn-outline-success]="action()?.status?.name !== 'Active'"
        (click)="onToggleStatus()"

    </div>

  @if (errorMessage()) {
    <div class="alert alert-danger mb-3">{{ errorMessage() }}</div>
  }

  @if (loading()) {
    <div class="text-center py-5">
      <div class="spinner-border text-primary" role="status"></div>
    </div>
  } @else {
    <!-- System entity banner -->
    @if (isProtected) {
      <div class="alert alert-info mb-3">
        {{ 'action_system_banner' | translate }}
      </div>
    }

    <!-- Section: Overview (form fields) -->
    <div class="card mb-4">
      <div class="card-header">{{ 'common_overview' | translate }}</div>
      <div class="card-body">
        <div class="row g-3">
          <div class="col-md-6">
            <nxgn-text-field
              [label]="'action_name_label' | translate"
              placeholder="e.g. My Action"
              [(value)]="name"
              [readonly]="isProtected"
              [errors]="nameErrors()"
            />
          </div>
          <div class="col-md-6">
            <nxgn-text-field
              [label]="'action_slug_label' | translate"
              [value]="slug()"
              (valueChange)="onSlugInput($event)"
              [disabled]="isEditMode()"
              [helperText]="isEditMode() ? '' : ('action_slug_helper' | translate)"
              [errors]="slugErrors()"
            />
          </div>
          @if (isEditMode() && action(); as a) {
            <div class="col-md-4">
              <label class="form-label">{{ 'common_status' | translate }}</label>
              <div>
                <span class="badge" [class]="a.status.name === 'Active' ? 'bg-success' : 'bg-warning text-dark'">
                  {{ a.status.name }}
                </span>
              </div>
            </div>
            <div class="col-md-4">
              <nxgn-text-field
                [label]="'common_created' | translate"
                [value]="(a.createdDate | date:'medium') ?? ''"
                [readonly]="true"
              />
            </div>
          }
        </div>
      </div>
    </div>

    <!-- Section: Embedded child grid -->
    <div class="card mb-4">
      <div class="card-body">
        <app-action-evidence-list
          [(evidence)]="evidence"
          [disabled]="isProtected"
          [showActions]="isEditMode()"
          (toggleStatus)="onToggleEvidenceStatus($event)"
          (rotateSecret)="onRotateSecret($event)"
        />
      </div>
    </div>

    <!-- Section: Read-only cross-references (edit mode only) -->
    @if (isEditMode() && action(); as a) {
      <div class="card mb-4">
        <div class="card-header d-flex justify-content-between align-items-center">
          <span>{{ 'action_org_usage' | translate }}</span>
          <span class="badge bg-secondary">{{ a.entitlements.length }}</span>
        </div>
        <div class="card-body">
          @for (ent of a.entitlements; track ent.workflow.id) {
            <div class="d-flex align-items-center justify-content-between item-row">
              <a [routerLink]="['/admin/workflows', ent.workflow.id]">
                {{ ent.workflow.name }}
              </a>
              <span class="badge" [class]="ent.entitlementStatus.name === 'Enabled' ? 'bg-success' : 'bg-warning text-dark'">

          } @empty {
            <p class="text-muted mb-0">{{ 'action_no_orgs' | translate }}</p>
          }
        </div>
      </div>
    }
  }
</div>
```

## Component Structure

```typescript
import { ChangeDetectionStrategy, Component, computed, effect, inject, input, signal } from '@angular/core';
import { DatePipe } from '@angular/common';
import { Router, RouterLink, RouterOutlet } from '@angular/router';
import { TranslatePipe, TranslateService } from '@ngx-translate/core';
import { ToastrService } from 'ngx-toastr';
import {
  TextFieldComponent,
  DropdownFieldComponent,
  CapturePageTitleComponent,
  ConfirmationDialogService,
} from '@nxgn-solutions/ui';

import { ActionDTO, ActionEvidenceDTO, SaveActionRequest } from './action.models';
import { ActionService } from './action.service';
import { ActionCaptureState } from './action-capture.state';
import { ActionEvidenceListComponent } from './action-evidence-list.component';

const EMPTY_GUID = '00000000-0000-0000-0000-000000000000';
const GUID_REGEX = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;
const SLUG_REGEX = /^[a-z][a-z0-9._-]*$/;

@Component({
  selector: 'app-action-capture',
  standalone: true,
  imports: [
    DatePipe,
    TranslatePipe,
    RouterLink,
    RouterOutlet,
    TextFieldComponent,
    CapturePageTitleComponent,
    ActionEvidenceListComponent,
  ],
  providers: [ActionCaptureState],  // Only if entity has child routes
  templateUrl: './action-capture.component.html',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class ActionCaptureComponent {
  private readonly router = inject(Router);
  private readonly toastr = inject(ToastrService);
  private readonly translate = inject(TranslateService);
  private readonly actionService = inject(ActionService);
  private readonly confirmService = inject(ConfirmationDialogService);
  private readonly state = inject(ActionCaptureState);  // Only if entity has child routes

  // --- Route param ---

  /** Bound from route param `:id` via withComponentInputBinding() */
  id = input<string>();

  isEditMode = computed(() => {
    const idVal = this.id();
    return !!idVal && GUID_REGEX.test(idVal);
  });

  // --- State ---

  loading = signal(false);
  saving = signal(false);
  errorMessage = signal('');
  action = signal<ActionDTO | null>(null);

  // --- Form fields ---

  name = signal('');
  slug = signal('');
  slugManuallyEdited = signal(false);

  // --- Aggregate children (delegated to state for child route access) ---

  evidence = this.state.evidence;

  /** Track server-assigned IDs to distinguish new vs existing items on save */
  private serverEvidenceIds = new Set<string>();

  /** Whether a child route (evidence capture) is active */
  childActive = signal(false);

  // --- Duplicate detection ---

  /** Unique names loaded from server, excluding current entity in edit mode */
  private uniqueNames = signal<string[]>([]);

  // --- Validation ---

  nameErrors = computed(() => {
    const n = this.name().trim();
    const errors: string[] = [];
    if (n.length > 255) errors.push(this.t('validation_name_max_length'));
    if (n && this.uniqueNames().some(u => u.toLowerCase() === n.toLowerCase())) {
      errors.push(this.t('validation_name_duplicate'));
    }
    return errors;
  });

  slugErrors = computed(() => {
    const s = this.slug().trim();
    const errors: string[] = [];
    if (s.length > 0 && !SLUG_REGEX.test(s)) {
      errors.push(this.t('validation_slug_pattern'));
    }
    if (s.length > 100) errors.push(this.t('validation_slug_max_length'));
    return errors;
  });

  isFormValid = computed(() => {
    if (this.saving() || this.loading()) return false;
    const n = this.name().trim();
    if (!n || n.length > 255) return false;
    if (this.nameErrors().length > 0) return false;
    const s = this.slug().trim();
    if (!s || s.length > 100 || !SLUG_REGEX.test(s)) return false;
    return true;
  });

  // --- System entity guard ---

  get isProtected(): boolean {
    const a = this.action();
    return !!a && a.isCore;
  }

  // --- Translation helper ---

  /** Synchronous translation — safe inside computed() */
  private t(key: string, params?: Record<string, unknown>): string {
    return this.translate.instant(key, params);
  }

  // --- Effects ---

  constructor() {
    // Load entity when route param changes to a valid GUID
    effect(() => {
      const idVal = this.id();
      if (idVal && GUID_REGEX.test(idVal)) {
        this.loadAction(idVal);
      }
    });

    // Auto-generate slug from name in create mode only
    effect(() => {
      const n = this.name();
      if (this.isEditMode() || this.slugManuallyEdited()) return;
      this.slug.set(this.generateSlug(n));
    });
  }

  // --- Slug input ---

  /** One-way binding + explicit handler to track manual edits */
  onSlugInput(value: string): void {
    this.slugManuallyEdited.set(true);
    this.slug.set(value);
  }

  // --- Load ---

  private async loadAction(id: string): Promise<void> {
    this.loading.set(true);
    this.errorMessage.set('');

    try {
      // 1. Fetch the aggregate DTO
      const dto = await this.actionService.get(id);
      this.action.set(dto);

      // 2. Populate form signals from DTO
      this.name.set(dto.name);
      this.slug.set(dto.slug);

      // 3. Populate aggregate children in state (for child route access)
      this.evidence.set(dto.evidence);
      this.state.actionId.set(dto.id);

      // 4. Snapshot server IDs for child diffing on save
      this.serverEvidenceIds = new Set(dto.evidence.map(c => c.id));

      // 5. Load secondary data in parallel
      await this.loadSecondaryData(dto);
    } catch {
      this.errorMessage.set(await firstValueFrom(this.translate.get('common_load_error')));
    } finally {
      this.loading.set(false);
    }
  }

  private async loadSecondaryData(dto: ActionDTO): Promise<void> {
    const [uniqueNames, complianceProfileOptions] = await Promise.all([
      this.actionService.getUniqueNames(dto.id),
      this.actionService.getComplianceProfileOptions(dto.slug),
    ]);
    this.uniqueNames.set(uniqueNames);
    this.state.complianceProfileOptions.set(complianceProfileOptions);
  }

  // --- Save ---

  async onSave(): Promise<void> {
    if (!this.isFormValid()) return;

    this.saving.set(true);
    this.errorMessage.set('');

    try {
      // 1. Diff children: new items get EMPTY_GUID, existing keep server ID
      const evidence = this.evidence().map(c => ({
        ...c,
        id: this.serverEvidenceIds.has(c.id) ? c.id : EMPTY_GUID,
      }));

      // 2. Build the save request
      const request: SaveActionRequest = {
        id: this.isEditMode() ? this.id()! : EMPTY_GUID,
        name: this.name().trim(),
        slug: this.slug().trim(),
        evidence,
      };

      // 3. Call the feature service
      const result = await this.actionService.save(request);

      // 4. Post-save behavior
      if (this.isEditMode()) {
        await this.loadAction(this.id()!);
        this.toastr.success(await firstValueFrom(this.translate.get('common_save_success')));
      } else {
        this.toastr.success(await firstValueFrom(this.translate.get('common_create_success')));
        this.router.navigate(['/admin/actions', result.id]);
      }
    } catch (err: unknown) {
      const msg = (err as { error?: { errors?: { message?: string }[] } })
        ?.error?.errors?.[0]?.message
```

```typescript
  slug = signal('');

  /** Whether a child route (evidence capture) is active */

  // --- Duplicate detection ---

  /** Unique names loaded from server, excluding current entity in edit mode */

  // --- Validation ---

      errors.push(this.t('validation_name_duplicate'));
    }
    return errors;
  });

  slugErrors = computed(() => {
    const s = this.slug().trim();
    const errors: string[] = [];
    if (s.length > 0 && !SLUG_REGEX.test(s)) {
      errors.push(this.t('validation_slug_pattern'));
    }
    if (s.length > 100) errors.push(this.t('validation_slug_max_length'));
    return errors;
  });

  isFormValid = computed(() => {
    if (this.saving() || this.loading()) return false;
    const n = this.name().trim();
    if (!n || n.length > 255) return false;
    if (this.nameErrors().length > 0) return false;
    const s = this.slug().trim();
    if (!s || s.length > 100 || !SLUG_REGEX.test(s)) return false;
    return true;
```

## Data Loading

### Load Trigger

Data loading is triggered by an `effect()` in the constructor that watches the route param `id`:

```typescript
effect(() => {
  const idVal = this.id();
  if (idVal && GUID_REGEX.test(idVal)) {
    this.loadAction(idVal);
  }
});
```

**Why `effect()` over `ngOnInit()`**: The route param is a signal input bound via `withComponentInputBinding()`. An effect reactively fires when it changes, which handles both initial load and subsequent navigation (e.g., browser back/forward). Capstone uses `ngOnInit()` + `history.state`, which breaks on browser refresh because `history.state` is lost.

### Load Method Structure

Every load method follows the same steps:

1. **Set loading state** — `this.loading.set(true)`
2. **Clear errors** — `this.errorMessage.set('')`
3. **Fetch the aggregate DTO** — `await this.actionService.get(id)`
4. **Populate form signals** — map DTO fields to individual signals
5. **Populate state service** — for child route access (if applicable)
6. **Snapshot server IDs** — `new Set(dto.evidence.map(c => c.id))` for child diffing
7. **Load secondary data** — lookups, unique names, permission types (parallel where possible)
8. **Handle errors** — catch block sets error message via translate
9. **Clear loading state** — `finally` block sets `this.loading.set(false)`

## Saving

### Child Diffing (Aggregate Save)

When the capture page manages an aggregate root with children, the save request must distinguish new items (insert) from existing items (update). The pattern:

1. **On load**: snapshot server-assigned IDs into a `Set<string>`
2. **During editing**: new children get temporary client-side UUIDs via `crypto.randomUUID()`
3. **On save**: map children — if the ID is in the server set, keep it; otherwise replace with `EMPTY_GUID`

```typescript
// On load — snapshot what the server knows about
this.serverEvidenceIds = new Set(dto.evidence.map(c => c.id));

// On save — new items get EMPTY_GUID so the API knows to insert
const evidence = this.evidence().map(c => ({
  ...c,
  id: this.serverEvidenceIds.has(c.id) ? c.id : EMPTY_GUID,
}));
```

The API's `EntityMapper` uses `EMPTY_GUID` to decide insert vs update, matching the backend [Entity Mapper pattern](../api/entity-mapper.md).

### Post-Save Behavior

| Mode | Action | Why |
|------|--------|-----|
| **Create** | Navigate to `/admin/actions/{newId}` | Show edit mode with server-assigned data (IDs, secrets, timestamps) |
| **Edit** | Reload entity via `loadAction(id)` | Refresh server state (computed fields, child IDs, status changes) |

### Form-Level Validity

A single `isFormValid` computed gates the Save button:

```typescript

  const s = this.slug().trim();
```

**Rules**:
- Disabled while saving or loading (prevents double-submit)
- Checks required fields (non-empty after trim)
- Checks field-level error arrays (catches duplicates, pattern violations)

### Translation Key Conventions

Keys use **dot-separated hierarchy**: `{feature}.{context}.{key}`. This is the ngx-translate standard and enables namespace-based lazy loading of translation files.

| Level | Pattern | Examples |
|-------|---------|----------|
| **Common** | `common.{key}` | `common.save`, `common.cancel`, `common.saving`, `common.delete`, `common.activate`, `common.deactivate` |
| **Feature page** | `{feature}.{page}.{key}` | `actions.list.title`, `actions.capture.title`, `workflows.list.title` |
| **Feature field** | `{feature}.fields.{field}` | `actions.fields.name`, `actions.fields.slug`, `workflows.fields.code` |
| **Feature action** | `{feature}.{action}.{outcome}` | `actions.delete.confirm`, `actions.delete.success`, `actions.status.title` |
| **Feature child** | `{feature}.{child}.{key}` | `actions.evidence.title`, `actions.evidence.deleteTitle`, `actions.consultations.title` |
| **Validation** | `validation.{rule}` | `validation.required`, `validation.maxLength`, `validation.duplicate`, `validation.slugPattern` |
| **Column headers** | `{feature}.columns.{field}` | `actions.columns.name`, `actions.columns.status`, `workflows.columns.code` |

**Rules:**
- Always lowercase, dot-separated — never underscores or camelCase in keys
- Feature name matches the route segment (`actions`, `workflows`, `compliance-profiles`)
- `common.*` for strings used by 2+ features
- `validation.*` for reusable validation messages
- Column headers use `{feature}.columns.*` — translated in `ngOnInit` via `firstValueFrom(translate.get(...))`
- Template strings use the `translate` pipe: `'actions.list.title' | translate`
- Code strings use `TranslateService`: `await firstValueFrom(this.translate.get('actions.delete.success'))`
- Parameterized keys: `'actions.delete.confirm' | translate:{ count: selected.length }`

## Domain Commands

Domain commands are actions beyond CRUD that change entity state (deactivate, rotate secret, toggle status, enable/disable action). They follow a consistent pattern:

```
confirm → execute → reload entity → toaster success
                  └→ toaster error (on failure)
```

### Implementation

```typescript
async onToggleStatus(): Promise<void> {
  const a = this.action();
  if (!a || a.isCore) return;  // Guard: no action on system entities

  const isActive = a.status.name === 'Active';
  const confirmed = await this.confirmService.confirm(
    await firstValueFrom(this.translate.get(
      isActive ? 'action_deactivate_confirm' : 'action_activate_confirm',
      { name: a.name },
    )),
    await firstValueFrom(this.translate.get('action_status_title')),
    {
      variant: isActive ? 'danger' : 'primary',
      confirmLabel: await firstValueFrom(
        this.translate.get(isActive ? 'common_deactivate' : 'common_activate'),
      ),
    },
  );
  if (!confirmed) return;

  try {
    const newStatus: EnumDTO = isActive
      ? { id: 1, name: 'Inactive' }
      : { id: 0, name: 'Active' };
    await this.actionService.updateStatus(a.id, { status: newStatus });
    await this.loadAction(a.id);  // Reload to reflect new state
    this.toastr.success(await firstValueFrom(this.translate.get('action_status_success')));
  } catch {
    this.toastr.error(await firstValueFrom(this.translate.get('action_status_error')));
  }
}
```

## Auto-Slug Pattern

Create-mode capture pages with a slug field auto-generate the slug from the name. The slug field uses one-way binding + explicit handler to track manual edits:

```typescript
// Signal tracking whether user has manually edited the slug
slugManuallyEdited = signal(false);

// Effect: auto-generate slug from name (create mode only, not manually edited)
effect(() => {
  const n = this.name();
  if (this.isEditMode() || this.slugManuallyEdited()) return;
  this.slug.set(this.generateSlug(n));
});

// Handler: mark slug as manually edited on first user input
onSlugInput(value: string): void {
  this.slugManuallyEdited.set(true);
  this.slug.set(value);
}
```

Template uses one-way binding for slug (not `[(value)]`):

```html
<!-- ✓ Correct — one-way binding + explicit handler -->
<nxgn-text-field
  [label]="'action_slug_label' | translate"
  [value]="slug()"
  (valueChange)="onSlugInput($event)"
  [disabled]="isEditMode()"
/>

<!-- ✗ Wrong — two-way binding triggers handler on every auto-generated change -->
<nxgn-text-field
  [(value)]="slug"
/>
```

**Why one-way**: Two-way binding would set `slugManuallyEdited` on every auto-generated change. One-way + explicit handler ensures the flag only sets when the **user** types.

## Key Rules

### Template

- Wrap all parent content in `<div [class.d-none]="childActive()">` if entity has child routes
- Use Bootstrap cards (`.card > .card-header + .card-body`) for form sections
- Use `@if` / `@for` / `@empty` — never `*ngIf` / `*ngFor`
- All user-facing strings through `translate` pipe — no hardcoded English
- Inline alerts for validation errors and saving indicator; toaster for success/error
- `DropdownFieldComponent` for classification fields with `{ id, name }` options

### Component

- `ChangeDetectionStrategy.OnPush` on every capture component
- `signal()` for each form field; `computed()` for derived validation and mode detection
- `effect()` in constructor for data loading and auto-slug — never `ngOnInit()`
- `inject()` for all dependencies — no constructor parameters
- Feature service for all HTTP — never raw `HttpClient` ([ADR-0007](../../adr/0007-feature-colocated-services-on-web.md))
- `firstValueFrom()` + `TranslateService.get()` for translated messages in code
- `EnumDTO` for all status/kind/mode fields, `NamedDTO` for FK references — never bare `string` or union types ([ADR-0005](../../adr/0005-enumdto-nameddto-for-ui-binding.md))

### Save Behavior

- Check `isFormValid()` before any work
- Set `saving(true)` → clear `errorMessage` → try/catch → `saving(false)` in finally
- Diff children via `serverIds` Set + `EMPTY_GUID` substitution
- Create mode: navigate to edit URL after save
- Edit mode: reload entity after save
- Always show toaster on success; show toaster + inline error on failure

### Navigation

- Cancel navigates to the list route (`/admin/{entity}`)
- Create mode save navigates to `/admin/{entity}/{newId}`
- Domain commands reload entity in place

## Departures from Capstone

| Concern | Capstone | Actions | Justification |
|---------|----------|----------|---------------|
| Mode detection | `history.state` from grid navigation | Route param GUID regex via `input()` | Survives browser refresh; `history.state` is lost on reload |
| Data loading | `ngOnInit()` → `CapturePageService.loadModel()` | `effect()` watching route param signal | Reactive; handles navigation changes automatically ([ADR-0006](../../adr/0006-signal-based-state-over-behaviorsubject.md)) |
| Service workflow | Centralized `CapturePageService` + `GridPageService` | Feature-colocated services | Vertical slice isolation; features are self-contained ([ADR-0007](../../adr/0007-feature-colocated-services-on-web.md)) |
| State management | Mutable model objects + default change detection | Immutable signals + OnPush | Predictable change tracking; explicit state flow ([ADR-0006](../../adr/0006-signal-based-state-over-behaviorsubject.md)) |
| Validation | Template-driven forms (`#form=ngForm` + `form.form.valid`) | Computed signal error arrays | Explicit, testable, OnPush-compatible |
| Post-save navigation | Always navigate to list | Reload entity (edit) / navigate to edit (create) | Aggregate pages need server-assigned state visible (child IDs, secrets, timestamps) |
| Child editing | Modals (`NgbModal`) | Child routes via `<router-outlet>` | Consistent URL model; deep-linkable; per project decision |
| Child data flow | Direct model mutation | Signal update via capture state service | Immutable; trackable; supports OnPush |
| ID generation | `Guid.create().toString()` (third-party library) | `crypto.randomUUID()` (browser native) | No dependency needed; built into modern browsers |

## Examples

### Aggregate root load and save

Lookup data and the aggregate root are loaded together, stitched into local state, then saved as one aggregate request.

```typescript
private async load(): Promise<void> {
  const id = this.id();
  const version = ++this.loadVersion;

  this.loading.set(true);
  try {
    const lookupsPromise = this.service.getLookups();

    if (id && GUID_REGEX.test(id)) {
      const [aggregate, lookups] = await Promise.all([
        this.service.get(id),
        lookupsPromise,
      ]);
      if (version !== this.loadVersion) return;

      this.lookups.set(lookups);
      this.aggregate.set(aggregate);
      this.childRows.set(stitchChildRows(aggregate, lookups));
      this.captureInitialState();
      return;
    }

    const lookups = await lookupsPromise;
    this.lookups.set(lookups);
    this.aggregate.set(createDraftAggregate(lookups));
    this.captureInitialState();
  } finally {
    if (version === this.loadVersion) this.loading.set(false);
  }
}

async onSave(): Promise<void> {
  const request: SaveAggregateRequest = buildSaveRequest(
    this.aggregate(),
    this.childRows(),
    this.lookups(),
  );

  await this.service.save(request);
}
```

## Rules

### MUST

- Aggregate-root create/edit pages must load foreign-key lookups in parallel with the aggregate root, stitch the editable aggregate client-side, and submit one Save request for the whole aggregate through the feature-colocated service.
- Aggregate-root Save requests must include all editable child collections and concurrency state needed for the API to map and save the aggregate in one database session.
- Aggregate capture pages must consume seeded translation keys for visible labels, validation summaries, lifecycle action text, and prerequisite empty states.

### MUST NOT

- Do not save aggregate child rows through separate per-row API calls from the capture page unless the design explicitly models a separate command outside the aggregate-root Save flow.
- Do not implement aggregate create/edit in modals; use routed capture pages with canDeactivate protection where unsaved changes are possible.
