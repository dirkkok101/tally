# Embedded List Pattern — NXGN Actions Web

> Generated from the lex graph. Do not edit this file as source of truth; update graph entities and re-export.

**Ref Code:** PAT-CORE-WEB-EMBEDDED-LIST

## Purpose

**AI Summary**: An embedded list manages child rows on a parent entity being edited. It renders inside a capture page using `nxgn-grid-page-title` + `nxgn-data-grid`, with checkbox multi-select and toolbar buttons for Add, Edit, and Delete. The component receives its data array via `model.required<T[]>()` for two-way binding, configuration flags via `input()`, and emits domain commands via `output()` — the parent owns the API calls. Local mutations (add, delete) update the model in place; the...

## Component Structure

Every embedded list component follows this skeleton. The canonical example is `ActionEvidenceListComponent`.

### TypeScript — `{entity}-list.component.ts`

```typescript
// From: Nxgn.Actions.Web.Ui/src/app/modules/admin/actions/action-evidence-list.component.ts
import { ChangeDetectionStrategy, Component, computed, inject, input, model, output, signal } from '@angular/core';
import { Router, ActivatedRoute } from '@angular/router';
import { TranslatePipe, TranslateService } from '@ngx-translate/core';
import { DataGridComponent, GridPageTitleComponent, ConfirmationDialogService } from '@nxgn-solutions/ui';
import { type ColDef, type RowDoubleClickedEvent } from 'ag-grid-community';

import { ActionEvidenceDTO } from './action.models';

@Component({
  selector: 'app-action-evidence-list',
  standalone: true,
  imports: [DataGridComponent, GridPageTitleComponent, TranslatePipe],
  template: `
    <nxgn-grid-page-title
      [title]="'actions.evidence.title' | translate"
      [showAdd]="!disabled()"
      [showDelete]="!disabled()"
      [selectedItems]="selectedItems()"
      (add)="onAdd()"
      (edit)="onEdit()"
      (delete)="onDelete()"
    >
      <!-- Domain command buttons go in the custom-buttons slot -->
      <ng-container custom-buttons>
        <button
          type="button"
          class="btn btn-sm btn-outline-secondary"
          [disabled]="!canMarkReviewed()"
          (click)="onMarkReviewed()"
        >
          {{ reviewStatusLabel() | translate }}
        </button>
      </ng-container>
    </nxgn-grid-page-title>
    <nxgn-data-grid
      [columnDefs]="columnDefs"
      [dataItems]="evidence()"
      [multiSelect]="true"
      (rowDoubleClicked)="onRowDoubleClicked($event)"
      (selectionChanged)="onSelectionChanged($event)"
    />
  `,
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class ActionEvidenceListComponent {
  private readonly router = inject(Router);
  private readonly route = inject(ActivatedRoute);
  private readonly confirmService = inject(ConfirmationDialogService);

  // --- Data binding ---
  /** Two-way bound child array from parent capture component */
  evidence = model.required<ActionEvidenceDTO[]>();

  // --- Configuration inputs ---
  /** Disable CRUD actions (e.g., system apps) */
  disabled = input(false);
  /** Whether to show domain command actions (only in edit mode with saved records) */
  showActions = input(false);

  // --- Domain command outputs (parent handles the API call) ---
  markReviewed = output<ActionEvidenceDTO>();

  // --- Local state ---
  selectedItems = signal<{ id: string }[]>([]);

  canMarkReviewed = computed(() => this.showActions() && this.selectedItems().length > 0);

  reviewStatusLabel = computed(() => {
    const selectedIds = new Set(this.selectedItems().map(s => s.id));
    const selected = this.evidence().filter(c => selectedIds.has(c.id));
    if (selected.length > 0 && selected.every(c => c.status.name === 'Approved')) return 'actions.evidence.reject';
    if (selected.length > 0 && selected.every(c => c.status.name === 'Rejected')) return 'actions.evidence.approve';
    return 'actions.evidence.reject';
  });

  // --- Column definitions ---
  columnDefs: ColDef<ActionEvidenceDTO>[] = [
    { field: 'fileName', headerName: 'File Name', flex: 1.5 },
    { field: 'description', headerName: 'Description', flex: 2 },
    {
      field: 'evidenceType',
      headerName: 'Type',
      flex: 0.8,
      valueFormatter: (params) => params.value?.name ?? '',
    },
    {
      field: 'status',
      headerName: 'Status',
      flex: 0.8,
      valueFormatter: (params) => params.value?.name ?? '',
    },
    {
      field: 'uploadedDate',
      headerName: 'Uploaded',
      flex: 1,
      valueFormatter: (params) =>
        params.value ? new Date(params.value).toLocaleDateString() : '',
    },
  ];

  // --- Navigation (child routes, not modals) ---
  onAdd(): void {
    this.router.navigate(['evidence', 'new'], { relativeTo: this.route });
  }

  onEdit(): void {
    const selected = this.selectedItems();
    if (selected.length === 1) {
      this.router.navigate(['evidence', selected[0].id], { relativeTo: this.route });
    }
  }

  onRowDoubleClicked(event: RowDoubleClickedEvent<ActionEvidenceDTO>): void {
    if (this.disabled() || !event.data) return;
    this.router.navigate(['evidence', event.data.id], { relativeTo: this.route });
  }

  // --- Local mutations (modify model in place, saved with parent) ---
  async onDelete(): Promise<void> {
    const selectedIds = new Set(this.selectedItems().map(s => s.id));
    if (selectedIds.size === 0) return;

    const confirmed = await this.confirmService.confirmDelete(
      await firstValueFrom(this.translate.get('actions.evidence.deleteTitle')),
      await firstValueFrom(this.translate.get('actions.evidence.deleteMessage', { count: selectedIds.size })),
    );
    if (!confirmed) return;

    this.evidence.update(list => list.filter(c => !selectedIds.has(c.id)));
    this.selectedItems.set([]);
  }

  // --- Domain command delegation ---
  onMarkReviewed(): void {
    const selectedIds = new Set(this.selectedItems().map(s => s.id));
    const selected = this.evidence().filter(c => selectedIds.has(c.id));
    for (const evidence of selected) {
      this.markReviewed.emit(evidence);
    }
  }

  // --- Grid selection tracking ---
  onSelectionChanged(rows: ActionEvidenceDTO[]): void {
    this.selectedItems.set(rows.map(r => ({ id: r.id })));
  }
}
```

### DTO — EnumDTO for Classification Fields

All classification fields on child DTOs MUST use `EnumDTO` ([ADR-0005](../../adr/0005-enumdto-nameddto-for-ui-binding.md)):

```typescript
// ✓ CORRECT — EnumDTO for classification fields (ADR-0005)
import { EnumDTO } from '@app/core/models/enum-dto';

export interface ActionEvidenceDTO {
  id: string;
  actionId: string;
  fileName: string;
  description: string | null;
  evidenceType: EnumDTO;        // { id: 0, name: "Document" }
  status: EnumDTO;              // { id: 0, name: "Pending" }
  fileUrl: string;
  uploadedDate: string;
}

// ✗ WRONG — bare string for classification fields
export interface ActionEvidenceDTO {
  evidenceType: string;       // ← violates ADR-0005
  status: string;             // ← violates ADR-0005
}

// ✗ WRONG — union types require transformation for dropdown binding
export type EvidenceType = 'Document' | 'Photo' | 'Video';
export interface ActionEvidenceDTO {
  evidenceType: EvidenceType;   // ← can't bind directly to dropdown
}
```

See [Feature Service — Model Rules](feature-service.md) for full DTO conventions.

### Minimal Variant — No Domain Commands

### Delete-Only Variant — No Add/Edit

Some embedded lists only support deletion. Steps on an workflow cannot be "added" through the embedded list — they are managed via a separate provisioning flow. Double-click navigates to a different feature (Users), not a child capture route.

```typescript
// From: Nxgn.Actions.Web.Ui/src/app/modules/admin/workflows/workflow-step-list.component.ts
@Component({
  selector: 'app-workflow-step-list',
  standalone: true,
  imports: [DataGridComponent, GridPageTitleComponent],
  template: `
    <nxgn-grid-page-title
      [title]="'workflows.steps.title' | translate"
      [showDelete]="true"
      [selectedItems]="selectedItems()"
      (delete)="onRemove()"
    />
    <nxgn-data-grid
      [columnDefs]="columnDefs"
      [dataItems]="steps()"
      [multiSelect]="true"
      (rowDoubleClicked)="onRowDoubleClicked($event)"
      (selectionChanged)="onSelectionChanged($event)"
    />
  `,
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class WorkflowStepListComponent {
  private readonly router = inject(Router);
  private readonly confirmService = inject(ConfirmationDialogService);

  steps = model.required<WorkflowStepDTO[]>();
  selectedItems = signal<{ id: string }[]>([]);

  columnDefs: ColDef<WorkflowStepDTO>[] = [
    { field: 'displayName', headerName: 'Name', flex: 1.5 },
    { field: 'email', headerName: 'Email', flex: 2 },
    { field: 'platformRole', headerName: 'Role', flex: 0.8 },
    {
      field: 'status',
      headerName: 'Status',
      flex: 0.8,
      cellClass: (params) => params.value === 'Active' ? 'badge-success' : 'badge-warning',
    },
    {
      field: 'joinedAt',
      headerName: 'Joined',
      flex: 1,
      valueFormatter: (params) =>
        params.value ? new Date(params.value).toLocaleDateString() : '',
    },

  onRowDoubleClicked(event: RowDoubleClickedEvent<WorkflowStepDTO>): void {

      this.router.navigate(['/admin/assigned-users', event.data.userId]);

  }

  async onRemove(): Promise<void> {
    const selectedIds = new Set(this.selectedItems().map(s => s.id));
    if (selectedIds.size === 0) return;

    const confirmed = await this.confirmService.confirmDelete(
      await firstValueFrom(this.translate.get('workflows.steps.removeTitle')),
      await firstValueFrom(this.translate.get('workflows.steps.removeMessage', { count: selectedIds.size })),
    );
    if (!confirmed) return;

    this.steps.update(list => list.filter(m => !selectedIds.has(m.id)));
    this.selectedItems.set([]);
  }

  onSelectionChanged(rows: WorkflowStepDTO[]): void {
    this.selectedItems.set(rows.map(r => ({ id: r.id })));
  }
}
```

### Parent Component Wiring

The parent capture page is responsible for:

1. **Owning the data** via [Capture State](capture-state.md) signals
2. **Mapping temp IDs** on save — new children have `crypto.randomUUID()` IDs that must become `EMPTY_GUID` before the API call
3. **Handling domain commands** by calling the [Feature Service](feature-service.md) and reloading
4. **Tracking server IDs** to distinguish new vs existing children

```typescript
// From: action-capture.component.ts

// Aggregate children — delegated to state so child routes can access them
evidence = this.state.evidence;
consultations = this.state.consultations;

/** Track IDs loaded from the server to distinguish new vs existing items */
private serverEvidenceIds = new Set<string>();
private serverConsultationIds = new Set<string>();

// On load: populate state and record server IDs
private async loadAction(id: string): Promise<void> {
  const actionData = await this.actionService.get(id);
  this.evidence.set(actionData.evidence);
  this.consultations.set(actionData.consultations);
  this.serverEvidenceIds = new Set(actionData.evidence.map(c => c.id));
  this.serverConsultationIds = new Set(actionData.consultations.map(c => c.id));
}

// On save: map temp UUIDs back to EMPTY_GUID for new items
async onSave(): Promise<void> {
  const evidence = this.evidence().map(c => ({
    ...c,
    id: this.serverEvidenceIds.has(c.id) ? c.id : EMPTY_GUID,
  }));
  const consultations = this.consultations().map(c => ({
    ...c,
    id: this.serverConsultationIds.has(c.id) ? c.id : EMPTY_GUID,
  }));

  const request: SaveActionRequest = {
    id: this.isEditMode() ? this.id()! : EMPTY_GUID,
    name: this.name().trim(),
    slug: this.slug().trim(),
    evidence,
    consultations,
  };

  const result = await this.actionService.save(request);
  // ... post-save handling
}

// Domain command handler: call API, reload entity
async onToggleEvidenceStatus(evidence: ActionEvidenceDTO): Promise<void> {
  const isApproved = evidence.status.name === 'Approved';
  const confirmed = await this.confirmService.confirm(
    await firstValueFrom(this.translate.get(
      isApproved ? 'actions.evidence.rejectConfirm' : 'actions.evidence.approveConfirm',
      { name: evidence.fileName },
    )),
    await firstValueFrom(this.translate.get('actions.evidence.statusTitle')),
    {
      variant: isApproved ? 'danger' : 'primary',
      confirmLabel: await firstValueFrom(this.translate.get(
        isApproved ? 'common.reject' : 'common.approve',
      )),
    },
  );
  if (!confirmed) return;

  const newStatus: EnumDTO = isApproved
    ? { id: 2, name: 'Rejected' }
    : { id: 1, name: 'Approved' };
  await this.actionService.setEvidenceStatus(this.action()!.id, evidence.id, { status: newStatus });
  await this.loadAction(this.action()!.id);  // Reload to reflect server state
}
```

## Key Rules

### Component API

| Mechanism | Purpose | When to use |
|-----------|---------|-------------|
| `model.required<T[]>()` | Two-way data binding with parent | Always — the child collection |
| `input()` | Read-only configuration flags | `disabled`, `showActions`, lookup data |
| `output<T>()` | Domain commands the parent executes | Server-side operations (mark reviewed, approve/reject) |

### Template Rules

- **MUST** use inline `template:` (not `templateUrl:`) — keeps the component self-contained
- **MUST** use `nxgn-grid-page-title` + `nxgn-data-grid` — same pair as [List Page](list-page.md)
- **MUST** set `[multiSelect]="true"` on the data grid
- **MUST** bind `[selectedItems]` to `nxgn-grid-page-title` — controls toolbar button state
- **MUST** import `TranslatePipe` and use the `translate` pipe for all user-facing strings
- **SHOULD** use `custom-buttons` content projection slot for domain command buttons
- **MUST NOT** use `templateUrl:` pointing to a separate HTML file

### Translation Rules

```typescript
// ✓ CORRECT — translate pipe for template strings
template: `
  <nxgn-grid-page-title

    ...
  />
`

// ✗ WRONG — hardcoded strings in templates

    ...
  />
```

### Mutation Rules

- **Local mutations** (add, delete, reorder): call `model.update(list => ...)` — changes are saved with the parent aggregate
- **Domain commands** (mark reviewed, approve/reject): emit via `output()` — parent calls the API and reloads
- **Always confirm destructive actions** via `ConfirmationDialogService.confirmDelete()`
- **Always clear `selectedItems`** after a delete mutation: `this.selectedItems.set([])`
- **Never call the API directly** from an embedded list component — the parent owns the service

```typescript
// ✓ CORRECT — local delete mutation with confirmation

    await firstValueFrom(this.translate.get('actions.evidence.deleteTitle')),
    await firstValueFrom(this.translate.get('actions.evidence.deleteMessage', { count: selectedIds.size })),
  );
  if (!confirmed) return;

}

// ✗ WRONG — calling API directly from embedded list

  await this.evidenceService.delete(selectedIds);  // ← parent owns the API
}
```

### Navigation Rules

- **Add/Edit** navigates to a child route when the embedded list has its own capture form: `this.router.navigate(['segment', id], { relativeTo: this.route })`
- **Never use modals** for add/edit — always child routes when a capture form is needed
- **Not all embedded lists have Add/Edit** — some only support Delete (e.g., `WorkflowStepListComponent` has Remove but no Add; double-click navigates to the User detail page instead)
- **Cross-feature double-click** (e.g., step → user detail) navigates to an absolute route

```typescript

  const modalRef = this.modalService.open(EvidenceCaptureComponent);  // ← use child routes
```

### ID Management

- New children get `crypto.randomUUID()` as a temp client-side ID
- Parent tracks `serverIds = new Set(loaded.map(x => x.id))` after load
- On save: `id: serverIds.has(item.id) ? item.id : EMPTY_GUID`
- `EMPTY_GUID = '00000000-0000-0000-0000-000000000000'` signals "create" to the backend

```typescript
// ✓ CORRECT — parent save maps temp IDs
const evidence = this.evidence().map(c => ({
  ...c,
  id: this.serverEvidenceIds.has(c.id) ? c.id : EMPTY_GUID,
}));

// ✗ WRONG — sending temp UUIDs to the backend
const evidence = this.evidence();  // ← temp UUIDs will confuse the backend
```

### DTO Rules

- All classification fields use `EnumDTO`, not bare `string` or union types ([ADR-0005](../../adr/0005-enumdto-nameddto-for-ui-binding.md))
- Child DTOs colocate with the parent: `ActionEvidenceDTO` in `action.models.ts`
- One DTO per entity — no duplicates like `MemberDTO` and `WorkflowStepDTO`
- All DTOs are `interface` with `{ get; set; }` properties — not `type` aliases or `class`

## Notification Rules

| Notification Type | Mechanism | Example |
|-------------------|-----------|---------|
| Domain command success/error | `ToastrService` (in parent) | "Evidence status updated" / "Failed to update evidence" |
| Delete confirmation | `ConfirmationDialogService.confirmDelete()` | Translated via `actions.evidence.deleteMessage` key |
| Domain command confirmation | `ConfirmationDialogService.confirm()` | Translated via `actions.evidence.approveConfirm` / `actions.evidence.rejectConfirm` keys |
| Validation errors | Not applicable — embedded lists have no form fields | — |

All notification messages MUST go through `@ngx-translate/core` for i18n support.

## Departures from Capstone

| Aspect | Capstone | Actions | Why |
|--------|----------|----------|-----|
| Data binding | `@Input() model` (mutable model class), `@ViewChild` for grid access | `model.required<T[]>()` (signal two-way binding) | [ADR-0006](../../adr/0006-signal-based-state-over-behaviorsubject.md) — signals over imperative state |
| DI style | Constructor injection | `inject()` function | Modern Angular standalone component convention |
| Change detection | Default (implicit) | `OnPush` (explicit) | Signal-based state enables OnPush everywhere |
| Templates | Separate `templateUrl` HTML files | Inline `template:` string | Embedded lists are small; inline keeps them self-contained |
| Add/Edit flow | Modal dialogs (`NgbModal`) | Child routes (`router.navigate`) | [ADR-0015](../../adr/0015-child-routes-over-modals-for-entity-capture.md) — child routes for list→capture navigation |
| Grid component | `NxgnGridComponent` (custom wrapper with `@ViewChild` imperative API) | `DataGridComponent` from `@nxgn-solutions/ui` (declarative input binding) | Shared UI library provides declarative grid |
| Grid title | `EntityGridLegendTitleComponent` | `GridPageTitleComponent` from `@nxgn-solutions/ui` | Shared UI library equivalent |
| Confirmation | `window.confirm()` with translated string | `ConfirmationDialogService.confirmDelete()` | Styled modal dialog consistent with app design |
| Selection tracking | `this.gridComponent.getSelectedNodes()` via `@ViewChild` | `(selectionChanged)` event → `signal<{ id: string }[]>` | Declarative signal flow avoids imperative grid access |
| Classification fields | String constants and raw strings | `EnumDTO` structured types | [ADR-0005](../../adr/0005-enumdto-nameddto-for-ui-binding.md) — zero-transformation dropdown roundtrip |
