```
  │

  ▼

  │
  ▼

  │ toastr.success('Created')
```

```
User is on /admin/actions/{id} (edit mode)
  │ Embedded list shows action evidence
  ▼
User clicks [+ Add Evidence] on embedded list
  │
  ▼
Router navigates to /admin/actions/{id}/evidence/new    ← child route
  │ Parent content hidden via CSS (d-none), NOT destroyed
  │ router-outlet activates child component
  ▼
Child component injects CaptureState
  │ Reads parent data (actionId, existing evidence for duplicate check)
  │ Generates temp UUID: private newRecordId = crypto.randomUUID()
  ▼
User fills child form → clicks [Save]
  │ Adds new item to state.evidence via state.evidence.update(list => [...list, newItem])
  │ newItem.id = this.newRecordId (temp client-side UUID)
  ▼
Router navigates back to /admin/actions/{id}
  │ Parent content shown again
  │ Embedded list reflects updated collection
  ▼
User clicks [Save] on PARENT capture page
  │ Parent maps child IDs: serverIds.has(id) ? id : EMPTY_GUID
  │ Sends full aggregate to API (parent + all children)
```

## Admin Configuration Module Minimum Surface

A user-configurable admin module must provide a permission-gated frontend route, menu visibility, seeded translation keys, a server-grid list, and a routed aggregate capture page. The list uses NxGN grid components and server-side grid data. The capture page is the client-side aggregate root: it loads aggregate data and lookup data in parallel, owns editable signal state, validates before save, and submits one Save request through the feature service.

## What Does My Feature Need?

Ask these questions before adding web feature infrastructure:

1. **Does the route only show a grid/list?**
   - Add a list page component and feature service.
   - Use the canonical `grid-list` backend route.

2. **Does the route capture one aggregate on one page, including embedded child tables?**
   - Add a routed capture component and a feature service.
   - Keep the aggregate state inside the component unless multiple child routes need to coordinate.

3. **Does the feature have nested child routes that edit the same draft aggregate?**
   - Add capture state.
   - Use the capture state as the client-side aggregate root across child route components.

4. **Does the feature only need lookup data?**
   - Use simple service methods or existing lookup helpers.
   - Do not add capture state or a grid abstraction.

Embedded tables inside one routed capture page do not require capture state by themselves. Capture state is for multi-route aggregate editing, not for every form that contains child collections.


### What Does My Feature Need? Example 1

```
Is this a new admin feature?
├── YES → Models + Feature Service + List Page + Capture Page + Routes
└── NO  → Only the specific pieces changing

Does the entity have children shown as embedded lists?
├── YES → Capture State (component-scoped Injectable)
│         Embedded List component(s)
│         Child route components for add/edit
│         ID management (crypto.randomUUID → EMPTY_GUID on save)
└── NO  → Simple capture page with direct form fields

Does the capture page need child routes?
├── YES → Capture State (mandatory — shares data between parent and child routes)
│         Child route definitions (shared between /new and /:id)
│         Parent template: d-none wrapper + router-outlet
└── NO  → No capture state needed

Does the entity have lifecycle commands (activate, disable)?
├── YES → Domain command buttons (custom-buttons slot on toolbar)
│         Confirmation dialogs before destructive commands
│         Feature service methods for each command
└── NO  → Standard CRUD only

Does the list page need custom filters?
├── YES → Query parameters on route (?action=abc123)
│         Filter UI in toolbar
└── NO  → Built-in grid search is sufficient
```

## Implementation Order

```
 1. Models — TypeScript interfaces mirroring API contracts
 2. Feature Service — HTTP methods (getGridList, get, save, delete)
 3. List Page — Grid with toolbar, selection, navigation
 4. Capture Page — Form with card sections, validation, save/cancel
 5. Capture State — Component-scoped state (only if aggregate with child routes)
 6. Embedded Lists — Child grids with add/edit/delete (only if aggregate)
 7. Child Route Components — Capture forms for child entities (only if child routes)
 8. Routing — Route definitions with lazy loading
 9. Validation — Per-field computed errors, isFormValid, duplicate detection
```

**Why this order?** Models define the shapes everything else references. The service provides the HTTP layer the components call. List page is the entry point users see first. Capture page is the primary interaction surface. State, embedded lists, and child routes layer on top for aggregates.

```typescript
  userId: string;

  email: string;

  id: string;
  name: string;
  slug: string;
  provisioningMode: EnumDTO;
  defaultRole: EnumDTO;
  domainAllowlist: string[] | null;
  requireReauthOnTenantSwitch: boolean;
  steps: WorkflowStepDTO[];
}

// Save response
export interface SaveWorkflowResponse {
  id: string;
}

// Shared types (from @nxgn-solutions/ui or shared models)
export interface EnumDTO {
  id: number;
  name: string;
}

export interface NamedDTO {
  id: string;
  name: string;
  description?: string;
}
```

### Model conventions

| Convention | Detail |
|-----------|--------|
| **All DTOs are interfaces** | Not classes — no runtime instantiation overhead |
| **EnumDTO for classifications** | `{ id: number, name: string }` — binds to dropdowns directly |
| **NamedDTO for FK references** | `{ id: string, name: string, description?: string }` |
| **Grid item DTOs are flat** | Scalar fields only — `stepCount: number` not `steps: []` |
| **Save request matches DTO shape** | Zero-transformation roundtrip: GET → mutate → POST |
| **ID is always `string`** | GUIDs are strings in TypeScript — `EMPTY_GUID = '00000000-0000-0000-0000-000000000000'` |
| **Dates are `string`** | ISO 8601 strings, not `Date` objects |
| **One models file per feature** | `{entity}.models.ts` co-located with service and components |

## Layer 2: Feature Service

HTTP service co-located with the feature. One service per feature, `providedIn: 'root'` or feature-scoped. All methods return `Promise<T>` (via `firstValueFrom`).

See [Feature Service](feature-service.md) for full conventions.

```typescript
// modules/admin/workflows/workflow.service.ts

import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { firstValueFrom } from 'rxjs';
import { GridListResponse } from '@nxgn-solutions/ui';
import {
  WorkflowDTO,
  WorkflowGridItemDTO,
  SaveWorkflowRequest,
  SaveWorkflowResponse,
} from './workflow.models';

@Injectable({ providedIn: 'root' })
export class WorkflowService {
  private readonly http = inject(HttpClient);
  private readonly baseUrl = '/api/v1/workflows';

  // Read operations
  getGridList(page: number, pageSize: number, search?: string): Promise<GridListResponse<WorkflowGridItemDTO>> {
    return firstValueFrom(
      this.http.post<GridListResponse<WorkflowGridItemDTO>>(
        `${this.baseUrl}/grid-list`,
        { page, pageSize, search }
      )
    );
  }

  get(id: string): Promise<WorkflowDTO> {
    return firstValueFrom(this.http.get<WorkflowDTO>(`${this.baseUrl}/${id}`));
  }

  // Write operations
  save(request: SaveWorkflowRequest): Promise<SaveWorkflowResponse> {
    return firstValueFrom(
      this.http.post<SaveWorkflowResponse>(this.baseUrl, request)
    );
  }

  delete(entityKeys: string[]): Promise<void> {
    return firstValueFrom(
      this.http.post<void>(`${this.baseUrl}/delete`, { entityKeys })
    );
  }

  // Lookups
  getLookupList(): Promise<NamedDTO[]> {
    return firstValueFrom(this.http.get<NamedDTO[]>(`${this.baseUrl}/lookup`));
  }

  // Domain commands (if applicable)
  setProvisioningMode(id: string, mode: EnumDTO): Promise<void> {
    return firstValueFrom(
      this.http.put<void>(`${this.baseUrl}/${id}/provisioning`, { provisioningMode: mode })
    );
  }
}
```

### Service conventions

| Convention | Detail |
|-----------|--------|
| **One service per feature** | Co-located in feature folder ([ADR-0007](../../adr/0007-feature-colocated-services-on-web.md)) |
| **`inject()` for DI** | Functional injection, no constructor parameters |
| **`firstValueFrom`** | Converts Observable to Promise — async/await in components |
| **Save is upsert** | Single `save()` method for create and update |
| **Delete is POST** | `POST /delete` with `{ entityKeys }` body (aggregate pattern) |
| **Grid list is POST** | `POST /grid-list` with filter payload |
| **Lookup returns NamedDTO[]** | For dropdowns and autocomplete |

```typescript
// modules/admin/workflows/workflow-list.component.ts

import { Component, inject, signal, OnInit, ChangeDetectionStrategy } from '@angular/core';
import { Router } from '@angular/router';
import { ColDef } from 'ag-grid-community';
import { TranslatePipe, TranslateService } from '@ngx-translate/core';
import { ToastrService } from 'ngx-toastr';
import { GridPageTitleComponent, DataGridComponent, ConfirmationDialogService } from '@nxgn-solutions/ui';
import { WorkflowService } from './workflow.service';
import { WorkflowGridItemDTO } from './workflow.models';

@Component({
  selector: 'app-workflow-list',
  standalone: true,
  changeDetection: ChangeDetectionStrategy.OnPush,
  imports: [GridPageTitleComponent, DataGridComponent, TranslatePipe],
  templateUrl: './workflow-list.component.html',
})
export class WorkflowListComponent implements OnInit {
  private readonly workflowService = inject(WorkflowService);
  private readonly router = inject(Router);
  private readonly toastr = inject(ToastrService);
  private readonly confirmService = inject(ConfirmationDialogService);
  private readonly translate = inject(TranslateService);

  // State signals
  readonly dataItems = signal<WorkflowGridItemDTO[]>([]);
  readonly loading = signal(true);
  readonly totalCount = signal(0);
  readonly selectedItems = signal<{ id: string }[]>([]);

  // Grid column definitions
  readonly columnDefs: ColDef<WorkflowGridItemDTO>[] = [
    { field: 'name', headerName: this.t('workflows.name') },
    { field: 'slug', headerName: this.t('workflows.slug') },
    {
      field: 'provisioningMode',
      headerName: this.t('workflows.provisioning_mode'),
      valueFormatter: (params) => params.value?.name ?? '',
    },
    { field: 'stepCount', headerName: this.t('workflows.step_count') },
    { field: 'createdDate', headerName: this.t('common.created_date') },
  ];

  ngOnInit(): void {
    this.loadGrid();
  }

  // Grid events
  onSelectionChanged(rows: WorkflowGridItemDTO[]): void {
    this.selectedItems.set(rows.map(r => ({ id: r.id })));
  }

  onRowDoubleClicked(row: WorkflowGridItemDTO): void {
    this.router.navigate(['/admin/workflows', row.id]);
  }

  // Toolbar actions
  onAdd(): void {
    this.router.navigate(['/admin/workflows/new']);
  }

  onEdit(): void {
    const selected = this.selectedItems();
    if (selected.length === 1) {
      this.router.navigate(['/admin/workflows', selected[0].id]);
    }
  }

  async onDelete(): Promise<void> {
    const selected = this.selectedItems();
    if (selected.length === 0) return;

    const confirmed = await this.confirmService.confirmDelete(
      this.t('workflows.delete_title'),
      this.t('workflows.delete_message', { count: selected.length })
    );
    if (!confirmed) return;

    try {
      await this.workflowService.delete(selected.map(s => s.id));
      this.toastr.success(this.t('workflows.deleted'));
      await this.loadGrid();
    } catch {
      this.toastr.error(this.t('common.delete_error'));
    }
  }

  // Data loading
  private async loadGrid(): Promise<void> {
    this.loading.set(true);
    try {
      const response = await this.workflowService.getGridList(1, 100);
      this.dataItems.set(response.items);
```

```typescript
// modules/admin/workflows/workflow-capture.component.ts

import {
  Component, inject, input, signal, computed, effect,
  ChangeDetectionStrategy,
} from '@angular/core';
import { Router, ActivatedRoute } from '@angular/router';
import { TranslatePipe, TranslateService } from '@ngx-translate/core';
import { ToastrService } from 'ngx-toastr';
import {
  CapturePageTitleComponent, TextFieldComponent, DropdownFieldComponent,
  CheckboxFieldComponent, TextAreaFieldComponent,
} from '@nxgn-solutions/ui';
import { WorkflowService } from './workflow.service';
import { WorkflowDTO, SaveWorkflowRequest, EnumDTO } from './workflow.models';

const EMPTY_GUID = '00000000-0000-0000-0000-000000000000';
const GUID_REGEX = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

@Component({
  selector: 'app-workflow-capture',
  standalone: true,
  changeDetection: ChangeDetectionStrategy.OnPush,
  imports: [
    CapturePageTitleComponent, TextFieldComponent, DropdownFieldComponent,
    CheckboxFieldComponent, TextAreaFieldComponent, TranslatePipe,
  ],
  templateUrl: './workflow-capture.component.html',
})
export class WorkflowCaptureComponent {
  private readonly workflowService = inject(WorkflowService);
  private readonly router = inject(Router);
  private readonly route = inject(ActivatedRoute);
  private readonly toastr = inject(ToastrService);
  private readonly translate = inject(TranslateService);

  // Route param (bound via withComponentInputBinding)
  readonly id = input<string>();

  // Mode detection
  readonly isEditMode = computed(() => GUID_REGEX.test(this.id() ?? ''));

  // Form field signals
  readonly name = signal('');
  readonly slug = signal('');
  readonly selectedProvisioningMode = signal<EnumDTO | null>(null);
  readonly selectedDefaultRole = signal<EnumDTO | null>(null);
  readonly domainAllowlist = signal('');
  readonly requireReauthOnTenantSwitch = signal(false);

  // Lookup data
  readonly provisioningModeOptions: EnumDTO[] = [
    { id: 0, name: 'Auto' },
    { id: 1, name: 'Manual' },
    { id: 2, name: 'Approval' },
  ];

  // UI state
  readonly loading = signal(false);
  readonly saving = signal(false);
  readonly errorMessage = signal('');
  private slugManuallyEdited = false;

  // Validation — per-field computed error arrays
  readonly nameErrors = computed(() => {
    const errors: string[] = [];
    const n = this.name().trim();
    if (!n) errors.push(this.t('validation.required'));
    if (n.length > 255) errors.push(this.t('validation.max_length', { max: 255 }));
    return errors;
  });

  readonly slugErrors = computed(() => {
    const errors: string[] = [];
    const s = this.slug().trim();
    if (!s) errors.push(this.t('validation.required'));
    if (s.length > 100) errors.push(this.t('validation.max_length', { max: 100 }));
    if (s && !/^[a-z0-9-]+$/.test(s)) errors.push(this.t('validation.slug_format'));
    return errors;
  });

  // Master form validity — gates Save button
  readonly isFormValid = computed(() => {
    if (this.saving() || this.loading()) return false;
    if (this.nameErrors().length > 0) return false;
    if (this.slugErrors().length > 0) return false;
    if (!this.selectedProvisioningMode()) return false;
    if (!this.selectedDefaultRole()) return false;
    return true;
  });

  constructor() {
    // Effect: load entity when route param changes (edit mode)
    effect(() => {
      const id = this.id();
      if (id && GUID_REGEX.test(id)) {
        this.loadEntity(id);
      }
    });

    // Effect: auto-generate slug from name (create mode only)
    effect(() => {
      const n = this.name();
      if (!this.isEditMode() && !this.slugManuallyEdited) {
        this.slug.set(n.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, ''));
      }
    });
  }

  // Slug manual edit tracking
  onSlugInput(): void {
    this.slugManuallyEdited = true;
  }

  // Save handler
  async onSave(): Promise<void> {
    if (!this.isFormValid()) return;

    this.saving.set(true);
    this.errorMessage.set('');

    try {
      const request: SaveWorkflowRequest = {
        id: this.isEditMode() ? this.id()! : EMPTY_GUID,
        name: this.name().trim(),
        slug: this.slug().trim(),
        provisioningMode: this.selectedProvisioningMode()!,
        defaultRole: this.selectedDefaultRole()!,
        domainAllowlist: this.domainAllowlist()
          ? this.domainAllowlist().split('\n').map(d => d.trim()).filter(Boolean)
          : null,
        requireReauthOnTenantSwitch: this.requireReauthOnTenantSwitch(),
        steps: [],  // simplified — see capture state for full step management
      };

      const response = await this.workflowService.save(request);

      if (!this.isEditMode()) {
        this.toastr.success(this.t('workflows.created'));
        this.router.navigate(['/admin/workflows', response.id]);
      } else {
        this.toastr.success(this.t('workflows.updated'));
        await this.loadEntity(this.id()!);
      }
    } catch (err: any) {
      this.errorMessage.set(err?.error?.message ?? this.t('common.save_error'));
    } finally {
      this.saving.set(false);
    }
  }

  onCancel(): void {
    this.router.navigate(['/admin/workflows']);
  }

  // Data loading
  private async loadEntity(id: string): Promise<void> {
    this.loading.set(true);
    try {
      const dto = await this.workflowService.get(id);
      this.name.set(dto.name);
      this.slug.set(dto.slug);
      this.selectedProvisioningMode.set(dto.provisioningMode);
      this.selectedDefaultRole.set(dto.defaultRole);
      this.domainAllowlist.set(dto.domainAllowlist?.join('\n') ?? '');
      this.requireReauthOnTenantSwitch.set(dto.requireReauthOnTenantSwitch);
    } catch {
      this.errorMessage.set(this.t('common.load_error'));
    } finally {
      this.loading.set(false);
    }
  }

  private t(key: string, params?: Record<string, unknown>): string {
    return this.translate.instant(key, params);
  }
}
```

## Layer 5: Capture State

Component-scoped `@Injectable()` that shares aggregate state between parent capture page and child route components. **Only needed when the capture page has child routes.**

See [Capture State](capture-state.md) for full conventions.

### When to use capture state

```
Capture page with NO child routes     → No capture state needed
```

## Layer 8: Validation

All validation is form-local using `computed()` error arrays. No external validation libraries. The `isFormValid` computed gates the Save button.

See [Validation](validation.md) for full conventions.

### Validation layers

```
Per-field errors (computed → string[])
  │ Required checks, length limits, format patterns
  │ Duplicate detection (server-loaded or sibling comparison)
  ▼
isFormValid (computed → boolean)
  │ All required fields non-empty
  │ All error arrays empty
  │ Not saving/loading
  ▼
Save button [disabled]="!isFormValid()"
  │
  ▼
API call
  │ Server-side validation (FluentValidation → 400)
  │ Business validation (command → exception)
  ▼
Error display
  │ API errors → inline alert (errorMessage signal)
  │ Field errors → [errors] binding on form components
```

### Per-field errors

```typescript
// Required + max length
readonly nameErrors = computed(() => {
  const errors: string[] = [];
  const n = this.name().trim();
  if (!n) errors.push(this.t('validation.required'));
  if (n.length > 255) errors.push(this.t('validation.max_length', { max: 255 }));
  return errors;
});

// Pattern validation
readonly slugErrors = computed(() => {
  const errors: string[] = [];
  const s = this.slug().trim();
  if (!s) errors.push(this.t('validation.required'));
  if (s && !/^[a-z0-9-]+$/.test(s)) errors.push(this.t('validation.slug_format'));
  return errors;
});

// Duplicate detection (aggregate root — server-loaded unique names)
readonly nameErrors = computed(() => {
  const errors: string[] = [];
  const n = this.name().trim().toLowerCase();
  if (this.uniqueNames().some(un => un.toLowerCase() === n)) {
    errors.push(this.t('validation.duplicate_name'));
  }
  return errors;
});

// Duplicate detection (child entity — sibling comparison via capture state)
readonly evidenceIdErrors = computed(() => {
  const errors: string[] = [];
  const cid = this.evidenceId().trim();
  const siblings = this.state.evidence().filter(c => c.id !== this.currentId);
  if (siblings.some(s => s.evidenceId === cid)) {
    errors.push(this.t('validation.duplicate_evidence_id'));
  }
  return errors;
});
```

### isFormValid

```typescript
readonly isFormValid = computed(() => {
  if (this.saving() || this.loading()) return false;
```

- [ ] List route: `{path}/`
- [ ] Create route: `{path}/new`
- [ ] Edit route: `{path}/:id`
- [ ] Lazy loading via `loadComponent`
- [ ] Child routes: shared definition applied to both `/new` and `/:id`
- [ ] Auth guard on `/admin` parent

### Cross-Cutting
- [ ] All strings translated (`translate` pipe + `TranslateService.instant()`)
- [ ] `standalone: true` + `ChangeDetectionStrategy.OnPush` on all components
- [ ] `inject()` for all service injection (no constructor params)
- [ ] Signal-based state (`signal()`, `computed()`, `effect()`)
- [ ] Confirmation dialogs before destructive actions
- [ ] Toast notifications for success/error feedback

## Rules

### MUST

- Admin list pages must use nxgn-content, nxgn-grid-page, nxgn-grid-page-title, and nxgn-server-grid backed by a server-side grid-list endpoint.
- Admin capture pages must use routed create/edit pages with nxgn-capture-page-title and feature-colocated services; aggregate roots must not be edited through modal CRUD.
- Capture pages that need foreign-key options must load lookup data in parallel with aggregate data and submit one aggregate Save request through the feature service.
- Menu labels, page titles, action labels, empty states, and validation summaries must consume seeded translation keys rather than hardcoded visible text.
- Feature routes must be permission-guarded using the frontend permission constants that correspond to backend permission catalogue and role-template grants.

### MUST NOT

- Do not implement client-side paging over a full table for admin catalogues; use nxgn-server-grid and the module grid-list endpoint.
