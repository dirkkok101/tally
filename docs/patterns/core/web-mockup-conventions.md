## Visual Vocabulary

Every UI element in a mockup maps to a specific component or pattern. Agents and reviewers MUST use these symbols consistently.

| Symbol | Meaning | Maps to |
|--------|---------|---------|
| `[Button]` | Toolbar action button | `nxgn-grid-page-title` or `nxgn-capture-page-title` button |
| `[Button ◌]` | Disabled button | `[disabled]="true"` or `[isValid]="false"` |
| `[Custom Button]` | Domain command button | `custom-buttons` content projection slot |
| `☐` | Unchecked row | `[multiSelect]="true"` on `nxgn-data-grid` |
| `☑` | Selected row | Selected row in grid |
| `[___________]` | Text input | `nxgn-text-field` with `[(value)]` binding |
| `[▼ dropdown ]` | Select dropdown | `nxgn-dropdown-field` with `[items]` of `EnumDTO[]` or `NamedDTO[]` |
| `[✓]` / `[ ]` | Checkbox | `nxgn-checkbox-field` |
| `⚠ message` | Inline validation error | `[errors]` array on field component |
| `┌ Section ──┐` | Card with header | Bootstrap `.card` + `.card-header` |
| `(n)` in header | Badge count | `<span class="badge bg-secondary">` |
| `Search: [__]` | Built-in grid search | `[showSearch]="true"` on `nxgn-data-grid` |

## Validation Error State

```
┌─────────────────────────────────────────────────────────────────┐
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  New Action                  [Save ◌] [Cancel]      │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  ┌ Overview ───────────────────────────────────────────────┐   │
│  │                                                          │   │
│  │  Name           [________________________________]       │   │
│  │                 ⚠ Name is required.                      │   │
│  │  Slug           [my app_________________________]        │   │
│  │                 ⚠ Must start with a lowercase letter;    │   │
│  │                   only lowercase letters, digits, dots,  │   │
│  │                   hyphens, underscores.                   │   │
│  │                                                          │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

- `[Save ◌]` indicates disabled state — `[isValid]="false"` on `nxgn-capture-page-title`
- `⚠` inline error below the field — from `computed()` error arrays
- Multiple errors can appear per field
- Save remains disabled until all errors clear (`isFormValid()` computed)

│  │  New Evidence                         [Save] [Cancel]      │   │

│  ┌ Evidence Details ─────────────────────────────────────────┐   │

│  │  Evidence ID      [________________________________]       │   │
│  │                 ⚠ This Evidence ID is already in use.      │   │
│  │  Display Name   [________________________________]       │   │
│  │  Type           [▼ Confidential ]                        │   │
│  │  Kind           [▼ Web          ]                        │   │

## Rules

### Layout

| Rule | Detail |
|------|--------|
| **Toolbar, not inline buttons** | Actions in `nxgn-grid-page-title` / `nxgn-capture-page-title`, never per-row |
| **Checkbox selection** | `☐` / `☑` column for multi-select, not row highlighting |
| **Search in grid** | Built-in `Search: [___]` row in `nxgn-data-grid`, not a custom search box |
| **Card sections** | Form groups in Bootstrap `.card` with `.card-header` label |
| **Embedded lists** | Child grids use the same toolbar+grid pattern, nested inside a card |
| **Empty states** | Grid shows centered message; Edit/Delete buttons hidden automatically |
| **Read-only sections** | Card with badge count `(n)` in header; shown only in edit mode |

### Title Convention

| Page Type | Title Pattern | Example |
|-----------|--------------|---------|
| List page | Entity plural | "Actions", "Users", "Roles" |
| Capture (create) | "New {Entity}" | "New Action", "New Role" |
| Capture (edit) | "Edit {Entity}: {name}" | "Edit Action: Safety Review" |
| Child capture (create) | "New {Child}" | "New Evidence", "New Consultation" |
| Child capture (edit) | "Edit {Child}: {name}" | "Edit Evidence: incident-photo.jpg" |

### Error and Feedback

| Rule | Detail |
|------|--------|
| **Inline validation** | `⚠` below the field — from `computed()` error arrays |
| **Duplicate detection** | `⚠ This {field} is already in use.` — client-side check against loaded values |
| **Server errors** | Alert banner between toolbar and form content |
| **Save disabled** | `[Save ◌]` when form invalid or saving in progress |
| **Confirmation required** | Modal dialog before every destructive action (delete, deactivate, revoke) |
| **Success feedback** | `ToastrService` notification (not shown in mockups — it's a toast overlay) |

### Data Display

| Rule | Detail |
|------|--------|
| **Status columns** | Display `EnumDTO.name` — "Active", "Inactive", "Pending" |
| **FK reference columns** | Display `NamedDTO.name` — "Safety Inspection", "ISO 45001" |
| **Boolean columns** | Display "Yes"/"No" or "Active"/"Inactive" |
| **Date columns** | Short date format (e.g., "3/1/26") |
| **Count footer** | `{n} {entity}(s)` at bottom of grid |
