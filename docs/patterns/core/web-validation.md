## Per-Field Validation

Each editable field has a `computed()` returning a `string[]` of error messages. Empty array = valid. The array is passed to form field components via `[errors]`.

```typescript
// ✓ Correct — computed error array with translated messages
nameErrors = computed(() => {
  const n = this.name().trim();
  const errors: string[] = [];
  if (n.length > 255) errors.push(this.t('validation_name_max_length'));
  if (n && this.uniqueNames().some(u => u.toLowerCase() === n.toLowerCase())) {
    errors.push(this.t('validation_name_duplicate'));
  }
  return errors;
});

slugErrors = computed(() => {
  const s = this.slug().trim();
  const errors: string[] = [];
  if (s.length > 0 && !SLUG_REGEX.test(s)) {
    errors.push(this.t('validation_slug_pattern'));
  }
  if (s.length > 100) {
    errors.push(this.t('validation_slug_max_length'));
  }
  return errors;
});
```

```html
<!-- ✓ Correct — pass error array to form field component -->
<nxgn-text-field
  [label]="'action_name' | translate"
  [(value)]="name"
  [errors]="nameErrors()"
/>

<nxgn-text-field
  [label]="'action_slug' | translate"

/>
```

### Common Mistakes

```typescript
// ✗ Wrong — hardcoded English strings
if (n.length > 255) errors.push('Name must be 255 characters or fewer.');

// ✓ Correct — translated messages
if (n.length > 255) errors.push(this.t('validation_name_max_length'));
```

```typescript
// ✗ Wrong — returning a single string
nameErrors = computed(() => {
  if (this.name().length > 255) return 'Too long';
  return '';
});

// ✓ Correct — always return string[]
nameErrors = computed(() => {
  const errors: string[] = [];
  if (this.name().trim().length > 255) errors.push(this.t('validation_name_max_length'));
  return errors;
});
```

### Translation Helper

Use a private helper to synchronously resolve translation keys within computed signals:

```typescript
private readonly translate = inject(TranslateService);

/** Synchronous translation — safe inside computed() */
private t(key: string, params?: Record<string, unknown>): string {
  return this.translate.instant(key, params);
}
```

> `TranslateService.instant()` is synchronous and safe inside `computed()`. Use `firstValueFrom(this.translate.get())` only in async methods (confirmation dialogs, toastr).

## Duplicate Detection

Two variants depending on whether the entity is an aggregate root or an aggregate child.

### Aggregate Roots — Server-Loaded Unique Names

Aggregate root entities (Actions, Workflows) load unique names from the server and check client-side for immediate feedback.

```typescript
// Signal holding taken names (excludes the entity being edited)
private uniqueNames = signal<string[]>([]);

// Load during entity load (edit mode) — exclude current entity
private async loadEntity(id: string): Promise<void> {
  const [dto, names] = await Promise.all([
    this.actionService.get(id),
    this.actionService.getUniqueNames(id),  // Excludes this entity's name
  ]);
  this.uniqueNames.set(names);
  // ... populate form signals
}

// Load during init (create mode) — all names
private async loadCreateData(): Promise<void> {
  const names = await this.actionService.getUniqueNames();
  this.uniqueNames.set(names);
}

// Validation checks against unique names (case-insensitive)
nameErrors = computed(() => {
  const n = this.name().trim();
  const errors: string[] = [];
  if (n.length > 255) errors.push(this.t('validation_name_max_length'));
  if (n && this.uniqueNames().some(u => u.toLowerCase() === n.toLowerCase())) {
    errors.push(this.t('validation_name_duplicate'));
  }
  return errors;
});
```

The feature service exposes the unique names endpoint:

```typescript
// In action.service.ts
async getUniqueNames(excludeId?: string): Promise<string[]> {
  const params = excludeId ? { excludeId } : {};
  return firstValueFrom(this.http.get<string[]>(`${this.apiBase}/unique-names`, { params }));
}
```

**Why client-side**: Immediate feedback without a round-trip per keystroke. The server still enforces uniqueness as the final authority — the client check is a UX optimization.

### Aggregate Children — Sibling Comparison

Child entities within an aggregate (e.g., consultations within an action, evidence within an action) check duplicates against siblings in the parent capture state. No server call needed — the parent already holds the full list.

```typescript
// In action-consultation-capture.component.ts

/** Existing names for duplicate detection (excludes the one being edited) */
private existingNames = computed(() =>
  this.state.consultations()
    .filter(t => t.id !== this.consultationRef())
    .map(t => t.name)
);

duplicateName = computed(() => {
  const n = this.name().trim().toLowerCase();
  return n.length > 0 && this.existingNames().some(
    existing => existing.toLowerCase() === n,
  );
});

isFormValid = computed(() => {
  const n = this.name().trim();
  return n.length > 0 && n.length <= 255 && !this.duplicateName();
});
```

```html
<!-- Child entities use @if for duplicate display (no [errors] binding) -->
@if (duplicateName()) {
  <small class="form-text text-danger">
    {{ 'validation_template_name_duplicate' | translate }}
  </small>
}
```

## Form-Level Validity

A single `isFormValid` computed gates the Save button via `nxgn-capture-page-title [isValid]`:

```typescript
isFormValid = computed(() => {
  // Block during async operations
  if (this.saving() || this.loading()) return false;

  // Required fields (non-empty after trim)
  const n = this.name().trim();
  if (!n || n.length > 255) return false;

  // Pattern validation
  const s = this.slug().trim();
  if (!s || s.length > 100) return false;
  if (!SLUG_REGEX.test(s)) return false;

  // Field-level error arrays (catches duplicates, pattern violations)
  if (this.nameErrors().length > 0) return false;
  if (this.slugErrors().length > 0) return false;

  return true;
});
```

**Rules**:
- Disabled while `saving()` or `loading()` — prevents double-submit
- Checks required fields (non-empty after trim)
- Checks field-level error arrays — catches duplicates and pattern violations
- Checks child-level duplicate booleans where applicable
- Returns `false` if any validation rule fails

```html
<nxgn-capture-page-title
  [title]="(isEditMode() ? 'action_edit_title' : 'action_new_title') | translate"
  [newRecord]="!isEditMode()"
  [isValid]="isFormValid()"
  (save)="onSave()"
  (cancel)="onCancel()"
/>
```

## Slug Auto-Generation

In create mode, auto-generate slug from name. Stop auto-generating once the user manually edits the slug field.

```typescript
slugManuallyEdited = signal(false);

constructor() {
  // Auto-generate slug from name in create mode only
  effect(() => {
    const n = this.name();
    if (this.isEditMode() || this.slugManuallyEdited()) return;
    this.slug.set(this.generateSlug(n));
  });
}

onSlugInput(value: string): void {
  this.slugManuallyEdited.set(true);
  this.slug.set(value);
}

private generateSlug(name: string): string {
  return name
    .toLowerCase()
    .trim()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
    .substring(0, 100);
}
```

```html
<!-- Bind slug field with manual edit detection -->
<nxgn-text-field
  [label]="'action_slug' | translate"
  [value]="slug()"
  (valueChange)="onSlugInput($event)"
  [errors]="slugErrors()"
  [disabled]="isEditMode()"
/>
```

## Confirmation Dialog

`ConfirmationDialogService` from `@nxgn-solutions/ui` wraps `NgbModal`. All confirmation text MUST use `ngx-translate`.

### Bulk Delete — `confirmDelete()`

Used on list pages for multi-select delete operations.

```typescript
async onDelete(): Promise<void> {
  const selected = this.selectedItems();
  if (selected.length === 0) return;

  const confirmed = await this.confirmService.confirmDelete(
    await firstValueFrom(this.translate.get('action_delete_title')),
    await firstValueFrom(this.translate.get('action_delete_confirm', { count: selected.length })),
  );
  if (!confirmed) return;

  try {
    await this.actionService.delete({ entityKeys: selected.map(s => s.id) });
    this.toastr.success(
      await firstValueFrom(this.translate.get('action_delete_success')),
    );
    await this.load();
  } catch {
    this.toastr.error(
      await firstValueFrom(this.translate.get('action_delete_error')),
    );
  }
}
```

### Domain Commands — `confirm()` with Variant

Used on capture pages for status changes, destructive operations, and irreversible actions.

```typescript
async onToggleStatus(): Promise<void> {
  const action = this.action();
  if (!action) return;

  const isActive = action.status.name === 'Active';
  const confirmed = await this.confirmService.confirm(
    await firstValueFrom(this.translate.get(
      isActive ? 'action_deactivate_confirm' : 'action_activate_confirm',
      { name: action.name },
    )),
    await firstValueFrom(this.translate.get(
      isActive ? 'action_deactivate_title' : 'action_activate_title',
    )),
    {
      variant: isActive ? 'danger' : 'primary',
      confirmLabel: await firstValueFrom(this.translate.get(
        isActive ? 'common_deactivate' : 'common_activate',
      )),
    },
  );
  if (!confirmed) return;

  try {
    const newStatus: EnumDTO = isActive
      ? { id: 1, name: 'Inactive' }
      : { id: 0, name: 'Active' };
    await this.actionService.updateStatus(action.id, { status: newStatus });
    this.toastr.success(
      await firstValueFrom(this.translate.get('action_status_updated')),
    );
    await this.loadEntity(action.id);
  } catch {
    this.errorMessage.set(
      await firstValueFrom(this.translate.get('action_status_error')),
    );
  }
}
```

### Confirmation API Reference

| Method | Parameters | Use Case |
|--------|------------|----------|
| `confirmDelete(title, message)` | Both strings (translated) | Bulk delete on list pages |
| `confirm(message, title, options?)` | `options.variant`: `'primary'` \| `'danger'`; `options.confirmLabel`: string | Domain commands, status toggles |

### When to Confirm

| Action | Confirm? | Method |
|--------|----------|--------|
| Bulk delete | Always | `confirmDelete()` |
| Status toggle (activate/deactivate) | Always | `confirm()` with `variant: 'danger'` for deactivate |
| Rotate secret | Always | `confirm()` with `variant: 'danger'` |
| Enable/disable child resource | Always for disable, skip for enable | `confirm()` |
| Save (create/update) | Never — `isFormValid` gates the button | N/A |

## Modal Pattern

Use `NgbModal` directly (not `ConfirmationDialogService`) for content display modals — data that must be shown once and cannot be retrieved again (e.g., generated secrets).

```typescript
private readonly modalService = inject(NgbModal);

private async showSecretsModal(generatedUrls: Record<string, string>): Promise<void> {
  const modalRef = this.modalService.open(GeneratedUrlsDisplayComponent, {
    centered: true,
    size: 'lg',
    backdrop: 'static',  // Prevent accidental dismissal
  });
  modalRef.componentInstance.generatedUrls = generatedUrls;
  try {
    await modalRef.result;
  } catch {
    // Dismissed — no action needed
  }
}
```

**Rules**:
- `backdrop: 'static'` for modals containing unretrievable data
- Pass data via `modalRef.componentInstance` properties
- Always `await modalRef.result` in a try/catch — modal dismissal throws
- Do NOT use modals for list→capture navigation — use child routes ([Routing](routing.md))

## Inline Error Display

### API Error Messages

Display API errors as inline alerts, not toasters. Clear on next save attempt.

```typescript
errorMessage = signal('');

async onSave(): Promise<void> {
  this.saving.set(true);
  this.errorMessage.set('');  // Clear previous error

  try {
    await this.actionService.save(request);
    this.toastr.success(await firstValueFrom(this.translate.get('common_save_success')));
  } catch (err: unknown) {
    const msg = (err as { error?: { errors?: { message?: string }[] } })
      ?.error?.errors?.[0]?.message
      ?? await firstValueFrom(this.translate.get('common_save_error'));
    this.errorMessage.set(msg);
  } finally {
    this.saving.set(false);
  }
}
```

```html
@if (errorMessage()) {
```

## Notification Rules

| Scenario | Mechanism | Example |
|----------|-----------|---------|
| Save success | `ToastrService.success()` | "Action saved" |
| Delete success | `ToastrService.success()` | "2 actions deleted" |
| Domain command success | `ToastrService.success()` | "Status updated" |
| API error on save | Inline alert (`errorMessage` signal) | Server validation message |
| API error on load | Inline alert (`errorMessage` signal) | "Failed to load action" |
| Field validation | `[errors]` on form component | Per-field error array |
| Duplicate name | `[errors]` or `@if` inline text | "This name is already in use" |
| Saving in progress | Inline spinner alert | Spinner + "Saving..." |

```typescript
// ✗ Wrong — toastr for field validation
if (this.nameErrors().length) this.toastr.error('Fix name errors');

// ✓ Correct — toastr only for page-level mutation results
this.toastr.success(await firstValueFrom(this.translate.get('action_saved')));
```

## Complete Capture Component Skeleton

Putting all validation patterns together for an aggregate root entity:

```typescript
import { ChangeDetectionStrategy, Component, computed, effect, inject, input, signal } from '@angular/core';
import { Router } from '@angular/router';
import { TranslateService } from '@ngx-translate/core';
import { ToastrService } from 'ngx-toastr';
import { firstValueFrom } from 'rxjs';
import {
  TextFieldComponent,
  CapturePageTitleComponent,
  ConfirmationDialogService,
} from '@nxgn-solutions/ui';

import { ActionDTO, SaveActionRequest } from './action.models';
import { ActionService } from './action.service';

const EMPTY_GUID = '00000000-0000-0000-0000-000000000000';
const GUID_REGEX = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;
const SLUG_REGEX = /^[a-z][a-z0-9._-]*$/;

@Component({
  selector: 'app-action-capture',
  standalone: true,
  imports: [TextFieldComponent, CapturePageTitleComponent],
  templateUrl: './action-capture.component.html',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class ActionCaptureComponent {
  private readonly router = inject(Router);
  private readonly actionService = inject(ActionService);
  private readonly confirmService = inject(ConfirmationDialogService);
  private readonly translate = inject(TranslateService);
  private readonly toastr = inject(ToastrService);

  id = input<string>();
  isEditMode = computed(() => {
    const idVal = this.id();
    return !!idVal && GUID_REGEX.test(idVal);
  });

  // State
  loading = signal(false);
  saving = signal(false);
  errorMessage = signal('');
  action = signal<ActionDTO | null>(null);

  // Form fields
  name = signal('');
  slug = signal('');
  slugManuallyEdited = signal(false);

  // Duplicate detection — server-loaded unique names
  private uniqueNames = signal<string[]>([]);

  // --- Per-field validation ---

  nameErrors = computed(() => {
    const n = this.name().trim();
    const errors: string[] = [];
    if (n.length > 255) errors.push(this.t('validation_name_max_length'));
    if (n && this.uniqueNames().some(u => u.toLowerCase() === n.toLowerCase())) {
      errors.push(this.t('validation_name_duplicate'));
    }
    return errors;
  });

  slugErrors = computed(() => {
    const s = this.slug().trim();
    const errors: string[] = [];
    if (s.length > 0 && !SLUG_REGEX.test(s)) {
      errors.push(this.t('validation_slug_pattern'));
    }
    if (s.length > 100) {
      errors.push(this.t('validation_slug_max_length'));
    }
    return errors;
  });

  // --- Form-level validity ---

  isFormValid = computed(() => {
    if (this.saving() || this.loading()) return false;
    const n = this.name().trim();
    if (!n || n.length > 255) return false;
    if (this.nameErrors().length > 0) return false;
    const s = this.slug().trim();
    if (!s || !SLUG_REGEX.test(s) || s.length > 100) return false;
    if (this.slugErrors().length > 0) return false;
    return true;
  });

  constructor() {
    effect(() => {
      const idVal = this.id();
      if (idVal && GUID_REGEX.test(idVal)) this.loadEntity(idVal);
    });

    effect(() => {
      const n = this.name();
      if (this.isEditMode() || this.slugManuallyEdited()) return;
      this.slug.set(this.generateSlug(n));
    });
  }

  // --- Save ---

  async onSave(): Promise<void> {
    if (!this.isFormValid()) return;
    this.saving.set(true);
    this.errorMessage.set('');

    try {
      const request: SaveActionRequest = {
        id: this.isEditMode() ? this.id()! : EMPTY_GUID,
        name: this.name().trim(),
        slug: this.slug().trim(),
      };
      const result = await this.actionService.save(request);
      this.toastr.success(await firstValueFrom(this.translate.get('action_saved')));

      if (this.isEditMode()) {
        await this.loadEntity(this.id()!);
      } else {
        this.router.navigate(['/admin/actions', result.id]);
      }
    } catch (err: unknown) {
      const msg = (err as { error?: { errors?: { message?: string }[] } })
        ?.error?.errors?.[0]?.message
        ?? await firstValueFrom(this.translate.get('common_save_error'));
      this.errorMessage.set(msg);
    } finally {
      this.saving.set(false);
    }
  }

  // --- Helpers ---

  private t(key: string, params?: Record<string, unknown>): string {
    return this.translate.instant(key, params);
  }

  private generateSlug(name: string): string {
    return name.toLowerCase().trim()
      .replace(/[^a-z0-9]+/g, '-')
      .replace(/^-+|-+$/g, '')
      .substring(0, 100);
  }

  private async loadEntity(id: string): Promise<void> {
    this.loading.set(true);
    this.errorMessage.set('');
    try {
      const [dto, names] = await Promise.all([
        this.actionService.get(id),
        this.actionService.getUniqueNames(id),
      ]);
      this.action.set(dto);
      this.name.set(dto.name);
      this.slug.set(dto.slug);
      this.uniqueNames.set(names);
    } catch {
      this.errorMessage.set(await firstValueFrom(this.translate.get('action_load_error')));
    } finally {
      this.loading.set(false);
    }
  }
}
```

## Departures from Capstone

| Concern | Capstone | Actions | Why |
|---------|----------|----------|-----|
| Field validation | `ControlValueAccessor` + `Validator` on shared input components | `computed(() => string[])` per field in capture component | Simpler, no wrapper needed. Signal-native (ADR-0006). Error arrays visible to `isFormValid` without form API. |
| Duplicate detection | `loadUniqueValues()` via `CapturePageService` | `getUniqueNames()` via feature service | Feature-colocated services (ADR-0007). No shared capture-page service. |
| Confirmation API | `confirm(config: ConfirmationDialogConfig)` with `showOk`/`showSave`/`showCancel` flags | `confirm(message, title, { variant, confirmLabel })` | Simplified API in `@nxgn-solutions/ui` v2. Same library, updated method signature. |
| Validation messages | Hardcoded English in some components | `ngx-translate` keys everywhere | i18n requirement for Actions platform |
| Success notifications | Not consistently used | `ToastrService.success()` after every mutation | User feedback for all state changes |
