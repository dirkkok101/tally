## Recipe

### Acceptance Checks

- The canonical cursor payload binds operation ID, page size, normalized AND-filters, expiry, snapshot/high-water fingerprints, and the exact keyset continuation tuple, then appends a SHA-256 checksum before base64url encoding.
- Decode rejects malformed base64url, unknown version/field, checksum mismatch, expiry, operation/filter/page-size mismatch, generation drift, and impossible keys before returning a resume position.
- Property tests prove identical inputs produce identical bytes and valid page traversals have no duplicate or omitted key at sizes 1 and 500.
- Cursors contain no description, amount, normalized token, path, corpus data, rule prose, secret, or mutation authority.

### Failure Criteria

- Do not use OFFSET pagination, durable server cursor state, encryption claims, caller-provided authority, or reflection JSON.
- Do not return a decoded position after any failed validation or convert cursor failure into an empty page.

### Expected Outputs

- ClassifyCursorCodec and ClassifyDiscoveryFilterFingerprint

### Constraints

- Cursor size is capped at 4096 UTF-8 bytes encoded and pageSize is 1 through 500.
