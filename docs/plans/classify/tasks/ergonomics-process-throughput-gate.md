## Recipe

### Acceptance Checks

- A published linux-x64 Native-AOT executable returns all 146 outcome rows at pageSize 500 in one initial CLI invocation, launches zero child process per row, completes within 5 seconds, and remains below 256 MiB peak resident memory on the release host.
- Larger bounded fixtures require exactly ceiling(filteredCount/pageSize) invocations; page sizes 1 and 500 have no duplicates/omissions and replay produces identical fingerprints.
- Each additive CLI path accepts stdin/file JSON according to its descriptor, writes one structured stdout envelope, maps every typed cursor/lifecycle/privacy/resource/integrity failure to the published exit code, and writes no private diagnostic.
- Outcome IDs compose into one unchanged selected_outcomes preview request; no test or helper launches outcome.get once per row.

- Do not measure in-process handlers as the throughput proof, hide publish/startup time, permit a five-minute timeout, or skip named-test discovery.
- Do not install, tag, release, deploy, or invoke live-data mutation.
