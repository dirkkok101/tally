## Recipe

### Acceptance Checks

- Validate the owner-only saved rulebook with the production validator, public LEDGER projection, and untracked representative 90-day corpus plus hold-out; never compile, seed, log, export, or commit personal values.
- Account for every row across eligible, suggested, correction, no-suggestion, conflict, excluded, and stale totals; exercise mixed, sign, account, fee, transfer, refund, and shared-medical canaries.
- Require zero incorrect applications, unexplained conflicts, unauthorized mutations, or description-inferred relationships; identical inputs are deterministic and drift canaries pass.
- Report aggregate-only coverage, no-suggestion, owner-decision, and elapsed-time evidence. Safety failure blocks authority; insufficient benefit requires an explicit owner decision, never an invented percentage.

### Failure Criteria

- Block activation, apply, command completion, and module completion on any safety, accounting, conflict, determinism, drift, privacy, or Ledger-truth failure.
- Never disclose private payloads or paths; infer Ledger state; discover or seed rules; broaden grammar; add an evaluator; weaken conflicts; or treat coverage as authority.
